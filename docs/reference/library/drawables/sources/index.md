# Sources

Drawables that import external media (video, image, backdrop) into the timeline.

- [**Video**](./video.md) — Imports a video file as a drawable.
- [**Image**](./image.md) — Imports a still image file as a drawable.
- [**Backdrop**](./backdrop.md) — Captures the rendered backdrop and exposes it as a drawable for blending.
