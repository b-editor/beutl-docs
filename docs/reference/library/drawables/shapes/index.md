# Shapes

Built-in shape drawables provided by Beutl. Each shape has its own size properties and can be styled with stroke and fill.

- [**Ellipse**](./ellipse.md) — Draws an ellipse or circle by width and height.
- [**Rectangle**](./rectangle.md) — Draws a rectangle by width and height.
- [**Rounded rectangle**](./rounded-rectangle.md) — Draws a rectangle with rounded corners.
- [**Geometry**](./geometry.md) — Draws an arbitrary path.
- [**Text**](./text.md) — Renders a string with the given font and style.
