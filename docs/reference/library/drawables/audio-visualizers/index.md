# Audio Visualizer

Drawables that visualize an audio signal (waveform, spectrum, spectrogram).

- [**Audio Waveform**](./audio-waveform.md) — Visualizes the audio signal as a waveform.
- [**Audio Spectrum**](./audio-spectrum.md) — Visualizes the audio frequency spectrum.
- [**Audio Spectrogram**](./audio-spectrogram.md) — Visualizes the audio spectrogram over time.
