# Drawables

This section documents Beutl's built-in drawable objects — anything that draws onto the canvas.

- [Shapes](./shapes/index.md) — primitive and text shapes
- [Sources](./sources/index.md) — video / image / backdrop sources
- [Particles](./particles/index.md) — particle emitters
- [Audio Visualizers](./audio-visualizers/index.md) — waveform / spectrum / spectrogram
- [Node-based](./node-based/index.md) — drawables driven by a node graph
- [Containers](../containers/index.md) — containers that group multiple objects together
