# Sound Group

Groups multiple sound sources and mixes them into a single output, allowing common gain / speed / effects to be applied to the entire group.

## Library location

Library → Sound Group

## Properties

_This object has no properties of its own. Only the inherited common properties are available._

## Common properties

This object inherits from `Sound` and exposes the [common properties](../common-properties.md) declared on its base classes.

## Usage

Use as a sub-mix bus: stem-bouncing dialog, music or SFX with shared processing.
