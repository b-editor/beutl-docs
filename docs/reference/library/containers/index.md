# Containers

Containers that wrap one or more children for grouping, decoration, or timing control.

- [**Decorator**](./decorator.md) — Wraps another drawable and applies extra transforms or effects to it.
- [**Group**](./group.md) — Groups multiple drawables and treats them as a single layer.
- [**Sound Group**](./sound-group.md) — Groups multiple sound sources and mixes them as a single output.
- [**Time Controller (Video)**](./time-controller-video.md) — Controls playback timing (offset and rate) of a child drawable.
