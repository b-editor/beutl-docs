# Script

Script-based filter effects let you implement custom shaders in C#, SKSL, or GLSL.

- [**C# Script**](./csharp-script.md) — Defines a custom filter effect in C#.
- [**SKSL Script**](./sksl-script.md) — Defines a custom filter effect with a SkiaSharp Shading Language (SKSL) shader.
- [**GLSL Script**](./glsl-script.md) — Defines a custom filter effect with a GLSL shader.
