# Layer

When a text object has `Split Per Character` enabled, or when `Split Equally` / `Split By Parts` has been applied — situations with multiple draw targets — this effect groups those targets into a single layer so filter effects operate on them as a whole.

## Library location

Library → Filter Effect → Layer

## Properties

_This object has no properties of its own._
