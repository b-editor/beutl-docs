# Portal

Portal objects sit on the timeline and capture the elements directly below them so container objects (Group, Decorator, Sound Group, 3D Scene, etc.) can adopt those elements as their children.

- [**Portal**](./portal-object.md) — Captures elements placed below it on the timeline so container objects can adopt them as children.
