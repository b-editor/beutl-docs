# Library reference

This section is a comprehensive reference covering all objects registered in the **"Library"** panel — including built-in drawables, sounds, transforms, filter effects, audio effects, and experimental 3D objects.
Brushes and pens are also documented here. They are not registered in the library but are used by some drawables.
