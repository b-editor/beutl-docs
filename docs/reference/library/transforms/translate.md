# Translate

Translates the layer along the X and Y axes. Both axes are independent and animatable.

## Library location

Library → Transform → Translate

## Properties

### X

Horizontal offset in pixels.

- **Type:** `float`
- **Default:** `0`
- **Animatable:** Yes

### Y

Vertical offset in pixels.

- **Type:** `float`
- **Default:** `0`
- **Animatable:** Yes

In the property panel, **X** and **Y** share one **Position** row. See [Values shown in one row](../../../get-started/keyframe.md#joined-rows).
