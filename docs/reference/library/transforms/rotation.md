# Rotation

Rotates the layer around its `Transform Origin` by the given angle, in degrees.

## Library location

Library → Transform → Rotation

## Properties

### Rotation

Rotation angle in degrees (positive = clockwise).

- **Type:** `float`
- **Default:** `0`
- **Animatable:** Yes
