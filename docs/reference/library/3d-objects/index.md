# 3D (Experimental)

Experimental 3D objects: scene container, primitives, models and lights. The 3D feature set is still under development.

- [**3D Scene**](./3d-scene.md) — A 3D rendering container with camera and lighting.
- [**Cube**](./cube.md) — A 3D cube primitive sized in width, height and depth.
- [**Sphere**](./sphere.md) — A 3D sphere primitive with a configurable radius and tessellation.
- [**Plane**](./plane.md) — A flat 3D plane sized in width and height with subdivision.
- [**Model**](./model.md) — Loads and renders an external 3D model file.
- [**Directional Light**](./directional-light.md) — A directional light source that illuminates the scene from a single direction.
- [**Point Light**](./point-light.md) — A point light that radiates from a single point in all directions.
- [**Spot Light**](./spot-light.md) — A cone-shaped spotlight with adjustable inner and outer angles.
