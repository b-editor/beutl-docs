Beutlでは多数のエフェクトを描画オブジェクトに適用できます。
このページではすべてのエフェクトをカテゴリ別に紹介します。

エフェクトの追加方法については[要素の編集](../get-started/5.edit-element.md)をご覧ください。

## ぼかし・モザイク

### ぼかし
ガウシアンぼかしを適用します。

| プロパティ | 説明 |
| --- | --- |
| シグマ | ぼかしの強さ (X, Y) |

### CvBlur (OpenCVぼかし)
OpenCVを用いた均一ぼかしです。

| プロパティ | 説明 |
| --- | --- |
| カーネルサイズ | ぼかしの範囲 |
| 画像サイズを固定 | 出力の画像サイズを元の画像に合わせる |

### CvGaussianBlur (OpenCVガウシアンぼかし)
OpenCVを用いたガウシアンぼかしです。

| プロパティ | 説明 |
| --- | --- |
| カーネルサイズ | ぼかしの範囲 |
| シグマ | ぼかしの強さ |
| 画像サイズを固定 | 出力の画像サイズを元の画像に合わせる |

### CvMedianBlur (OpenCVメディアンぼかし)
OpenCVを用いたメディアンぼかしです。ノイズ除去に効果的です。

| プロパティ | 説明 |
| --- | --- |
| カーネルサイズ | ぼかしの範囲 |
| 画像サイズを固定 | 出力の画像サイズを元の画像に合わせる |

### モザイク
画像をピクセル化（モザイク処理）します。

| プロパティ | 説明 |
| --- | --- |
| タイルサイズ | タイルのサイズ (幅, 高さ)。デフォルト: 10x10 |
| 原点 | モザイクの原点。デフォルト: 中央 |

| プロパティ | 説明 |
| --- | --- |
| 量 | 明るさのパーセンテージ。デフォルト: 100 |

### 彩度調整

| プロパティ | 説明 |
| --- | --- |
| 量 | 彩度のパーセンテージ。デフォルト: 100 |

### 色相調整

| プロパティ | 説明 |
| --- | --- |

### ガンマ

| プロパティ | 説明 |

| 強さ | エフェクトの強さ (0-100)。デフォルト: 100 |

### ハイコントラスト

### 二階調化

| プロパティ | 説明 |

## カラーグレーディング

### カラーグレーディング
プロフェッショナルなカラーグレーディングを行います。リフト・ガンマ・ゲインモデルを使用し、色温度の制御やHSV調整ができます。

| プロパティ | 説明 |
| --- | --- |
| 色温度 | 色温度 (-100 〜 100) |
| 色かぶり補正 | 色合い (-100 〜 100) |
| 露出 | 露出 (-5 〜 5) |
| コントラスト | コントラスト (-100 〜 100) |
| コントラストのピボット | コントラストの中間値 (0 〜 1)。デフォルト: 0.5 |
| 彩度 | 彩度 (-100 〜 100) |
| バイブランス | 自然な彩度 (-100 〜 100) |
| 色相 | 色相 (-180 〜 180) |
| ローレンジ | シャドウの範囲 (0 〜 100)。デフォルト: 40 |
| ハイレンジ | ハイライトの範囲 (0 〜 100)。デフォルト: 60 |
| シャドウ | シャドウの色調整 |
| ミッドトーン | 中間トーンの色調整 |
| ハイライト | ハイライトの色調整 |
| リフト | リフト (暗部の調整) |
| ガンマ | ガンマ (中間トーンの調整) |
| ゲイン | ゲイン (明部の調整) |
| オフセット | オフセット (全体の調整) |

### カーブ
RGB各チャンネルの入出力カーブを使って詳細な色補正を行います。

| プロパティ | 説明 |
| --- | --- |
| カスタム(RGB) | マスターカーブ |
| レッドカーブ | 赤チャンネルのカーブ |
| グリーンカーブ | 緑チャンネルのカーブ |
| ブルーカーブ | 青チャンネルのカーブ |
| 色相 vs 色相 | 色相に基づく色相の調整 |
| 色相 vs 彩度 | 色相に基づく彩度の調整 |
| 色相 vs 輝度 | 色相に基づく輝度の調整 |
| 輝度 vs 彩度 | 輝度に基づく彩度の調整 |
| 彩度 vs 彩度 | 彩度に基づく彩度の調整 |

### LUT (Cubeファイル)
3D LUT (Look-Up Table) ファイルを使って色変換を適用します。`.cube`ファイルに対応しています。

| プロパティ | 説明 |
| --- | --- |
| ソース | LUTファイル |
| 強さ | LUTの適用強度 (0-100)。デフォルト: 100 |

### 明るさ調整

| プロパティ | 説明 |
| --- | --- |
| 乗算 | 乗算色。デフォルト: 白 |
| 加算 | 加算色。デフォルト: 透明 |

## エフェクトの種類について

エフェクトは内部的に3つの種類に分けられます。

1. **画像フィルタ** - ぼかし、ドロップシャドウなど。他の画像フィルタと合成できます。
2. **色フィルタ** - 色相調整、ハイコントラストなど。画像フィルタに変換できます。
3. **カスタムエフェクト** - CvBlurなどの外部ライブラリを使ったエフェクト。ラスター化された画像が必要です。

Beutlはこれらのエフェクトを自動的に最適化し、可能な限り効率的に処理します。
詳細は[エフェクトの適用プロセス](../advanced/3.filter-effect.md)をご覧ください。
