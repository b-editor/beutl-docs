# ブレンドモード

ブレンドモードは、レイヤーやオブジェクトが下のレイヤーとどのように合成されるかを制御する機能です。異なるブレンドモードを使用することで、さまざまな視覚効果を作成できます。

## ブレンドモードの概要

ブレンドモードは、上のレイヤー（ソース）と下のレイヤー（デスティネーション）の色をどのように混ぜ合わせるかを定義します。Beutlでは、29種類のブレンドモードが用意されています。

## ブレンドモード一覧

| 名前 | 説明 |
|------|------|
| クリア | デスティネーションの内容をクリアします。結果は透明になります |
| 上書き | ソースの内容でデスティネーションを完全に上書きします |
| そのまま | デスティネーションをそのまま保持し、ソースは表示されません |
| 前面合成 | ソースをデスティネーションの前面に配置します。標準的な合成方法です |
| 背面合成 | ソースをデスティネーションの背面に配置します |
| 前面内描画 | ソースとデスティネーションが重なる部分のみを表示します（ソースの色） |
| 背面内描画 | ソースとデスティネーションが重なる部分のみを表示します（デスティネーションの色） |
| 前面外描画 | ソースとデスティネーションが重ならない部分のソースを表示します |
| 背面外描画 | ソースとデスティネーションが重ならない部分のデスティネーションを表示します |
| 前面上描画 | デスティネーションがある部分にのみソースを描画します |
| 背面上描画 | ソースがある部分にのみデスティネーションを描画します |
| 排他的合成 | ソースとデスティネーションが重ならない部分のみを表示します |
| 加算 | ソースとデスティネーションの色を加算します。明るくなります |
| 変調 | ソースとデスティネーションの色を乗算します。暗くなります |
| スクリーン | 反転した色を乗算してから反転します。明るくなります |
| オーバーレイ | 暗い部分は変調、明るい部分はスクリーンで合成します |
| 比較（暗） | ソースとデスティネーションの暗い方の色を選択します |
| 比較（明） | ソースとデスティネーションの明るい方の色を選択します |
| 覆い焼きカラー | デスティネーションの色を明るくします。光を当てたような効果 |
| 焼き込みカラー | デスティネーションの色を暗くします。コントラストが強くなります |
| ハードライト | オーバーレイの逆。ソースの明暗に応じて変調またはスクリーン |
| ソフトライト | ハードライトよりも柔らかい効果 |
| 差の絶対値 | ソースとデスティネーションの色の差の絶対値を表示します |
| 除外 | 差の絶対値に似ていますが、コントラストが低くなります |
| 乗算 | ソースとデスティネーションの色を乗算します。変調よりも暗くなります |
| 色相 | デスティネーションの彩度と輝度を保ち、ソースの色相を適用します |
| 彩度 | デスティネーションの色相と輝度を保ち、ソースの彩度を適用します |
| カラー | デスティネーションの輝度を保ち、ソースの色相と彩度を適用します |
| 輝度 | デスティネーションの色相と彩度を保ち、ソースの輝度を適用します |

## ブレンドモードのカテゴリ

### 基本的な合成

- **クリア**、**上書き**、**そのまま**：基本的な描画制御
- **前面合成**、**背面合成**：標準的なレイヤー合成

### マスク系

- **前面内描画**、**背面内描画**：重なる部分のみを表示
- **前面外描画**、**背面外描画**：重ならない部分を表示
- **前面上描画**、**背面上描画**：特定の領域にのみ描画
- **排他的合成**：重ならない部分のみを表示

### 明度調整

- **加算**：色を加算して明るくします。光の効果に最適
- **スクリーン**：柔らかく明るくします
- **覆い焼きカラー**：強い明るさの効果

### 暗度調整

- **変調**、**乗算**：色を暗くします
- **焼き込みカラー**：コントラストを強めながら暗くします

### コントラスト調整

- **オーバーレイ**：明るい部分はより明るく、暗い部分はより暗く
- **ハードライト**：オーバーレイの強いバージョン
- **ソフトライト**：オーバーレイの柔らかいバージョン

### 比較・差分

- **比較（暗）**、**比較（明）**：色を比較して選択
- **差の絶対値**：色の差を表示。反転効果に使えます
- **除外**：差の絶対値の柔らかいバージョン

### 色調整

- **色相**：色合いのみを変更
- **彩度**：鮮やかさのみを変更
- **カラー**：色合いと鮮やかさを変更
- **輝度**：明るさのみを変更

## 使用例

### 光の効果

**加算**ブレンドモードを使用して、光や炎などの発光効果を作成：

1. 光源となるオブジェクトを作成
2. ブレンドモードを「加算」に設定
3. 複数の光源を重ねると、より明るく光ります

### テクスチャの重ね合わせ

**オーバーレイ**ブレンドモードを使用して、テクスチャを自然に重ねる：

1. ベースとなる画像レイヤー
2. その上にテクスチャレイヤーを配置
3. テクスチャレイヤーのブレンドモードを「オーバーレイ」に設定

### カラーグレーディング

**カラー**ブレンドモードを使用して、映像の色調を調整：

1. 映像レイヤーの上に、単色の塗りつぶしレイヤーを配置
2. 塗りつぶしレイヤーのブレンドモードを「カラー」に設定
3. 塗りつぶしの色を変更して、映像全体の色調を変更

### 影の追加

**乗算**ブレンドモードを使用して、自然な影を作成：

1. オブジェクトの下に、影となる暗い形状を配置
2. 影レイヤーのブレンドモードを「乗算」に設定
3. 不透明度を調整して、影の濃さを調整

### サイケデリックな効果

**差の絶対値**ブレンドモードを使用して、独特の視覚効果を作成：

1. 動くオブジェクトを複製
2. 複製したレイヤーのブレンドモードを「差の絶対値」に設定
3. 複製レイヤーを少しずらしてアニメーション

## ヒント

- ブレンドモードは、不透明度と組み合わせることで、より繊細な効果を作成できます
- 同じブレンドモードでも、色によって結果が大きく変わります。実験してみることが重要です
- 複数のレイヤーで異なるブレンドモードを使用することで、複雑な合成効果を実現できます
- **前面合成**が最も一般的なブレンドモードで、通常のレイヤー重ね合わせに使用されます
- 光の効果には**加算**、影の効果には**乗算**が適しています
- **スクリーン**と**オーバーレイ**は、写真の補正やエフェクトに頻繁に使用されます
