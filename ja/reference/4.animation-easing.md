# アニメーション・イージング関数

イージング関数は、アニメーションの動きに緩急をつけるための関数です。キーフレーム間の補間方法を変更することで、より自然で魅力的なアニメーションを作成できます。

## イージング関数の概要

イージング関数は、時間の経過に対する値の変化率を制御します。例えば：

- **イーズイン** - ゆっくり始まり、徐々に加速します
- **イーズアウト** - 速く始まり、徐々に減速します
- **イーズインアウト** - ゆっくり始まり、加速し、最後に減速します

## リニア

| 名前 | 説明 |
|------|------|
| リニア | 等速の動き。始まりから終わりまで一定の速度で変化します |

## サイン

| 名前 | 説明 |
|------|------|
| サインイーズイン | サイン曲線を使った緩やかな加速 |
| サインイーズインアウト | サイン曲線を使った緩やかな加速と減速 |
| サインイーズアウト | サイン曲線を使った緩やかな減速 |

## 二次

| 名前 | 説明 |
|------|------|
| 二次イーズイン | 二次関数による加速。徐々に速くなります |
| 二次イーズインアウト | 二次関数による加速と減速 |
| 二次イーズアウト | 二次関数による減速。徐々に遅くなります |

## 三次

| 名前 | 説明 |
|------|------|
| 三次イーズイン | 三次関数による加速。二次より強い加速 |
| 三次イーズインアウト | 三次関数による加速と減速 |
| 三次イーズアウト | 三次関数による減速。二次より強い減速 |

## 四次

| 名前 | 説明 |
|------|------|
| 四次イーズイン | 四次関数による加速。より強い加速 |
| 四次イーズインアウト | 四次関数による加速と減速 |
| 四次イーズアウト | 四次関数による減速。より強い減速 |

## 五次

| 名前 | 説明 |
|------|------|
| 五次イーズイン | 五次関数による加速。非常に強い加速 |
| 五次イーズインアウト | 五次関数による加速と減速 |
| 五次イーズアウト | 五次関数による減速。非常に強い減速 |

## 指数

| 名前 | 説明 |
|------|------|
| 指数イーズイン | 指数関数による急激な加速 |
| 指数イーズインアウト | 指数関数による急激な加速と減速 |
| 指数イーズアウト | 指数関数による急激な減速 |

## 円

| 名前 | 説明 |
|------|------|
| 円イーズイン | 円の四分の一の曲線による加速 |
| 円イーズインアウト | 円の曲線による加速と減速 |
| 円イーズアウト | 円の四分の一の曲線による減速 |

## バック

| 名前 | 説明 |
|------|------|
| バックイーズイン | 開始前に少し逆方向に動いてから加速。予備動作のような効果 |
| バックイーズインアウト | 開始と終了時に逆方向に動く |
| バックイーズアウト | 終了時に目標を超えて戻る。オーバーシュート効果 |

## バウンス

| 名前 | 説明 |
|------|------|
| バウンスイーズイン | ボールが跳ねるような動きで加速 |
| バウンスイーズインアウト | 開始と終了時にボールが跳ねるような動き |
| バウンスイーズアウト | ボールが着地して跳ねるような動き |

## エラスティック

| 名前 | 説明 |
|------|------|
| エラスティックイーズイン | ゴムのように振動しながら加速 |
| エラスティックイーズインアウト | 開始と終了時にゴムのように振動 |
| エラスティックイーズアウト | ゴムのように振動しながら減速。バネのような効果 |

## スプライン

| 名前 | 説明 |
|------|------|
| スプライン | カスタムのベジェ曲線で自由にイージングを定義できます |

### スプラインイージングの使い方

スプラインイージングを選択すると、カスタムのベジェ曲線を編集できるエディタが表示されます。

- **コントロールポイント** - 曲線の形を調整するための制御点
- **ハンドル** - コントロールポイントの接線を調整するハンドル
- **プリセット** - よく使われるイージングのプリセットから選択できます

コントロールポイントをドラッグして、独自のイージングカーブを作成できます。これにより、標準のイージング関数では実現できない、複雑で独特な動きを表現できます。

## 使用例

### 滑らかなフェードイン

テキストや画像を滑らかにフェードインさせる場合：

- **サインイーズアウト** または **二次イーズアウト** が適しています

### ボタンのホバーエフェクト

UIボタンが反応する際の動き：

- **バックイーズアウト** で、少しオーバーシュートする動きが効果的です

### ページ遷移

画面全体が切り替わるようなアニメーション：

- **三次イーズインアウト** で、始まりと終わりが滑らかな動きを実現できます

### 弾むボール

物理的なボールの動きを表現する場合：

- **バウンスイーズアウト** で、リアルな跳ね返りを表現できます

## ヒント

- 多くの場合、**インアウト**タイプのイージングが自然な動きを生み出します
- **バック**や**エラスティック**は、UIアニメーションで注目を集めるのに効果的です
- **リニア**は、機械的な動きや一定速度が必要な場合に使用します
- 複数のキーフレームで異なるイージングを組み合わせることで、より複雑で表現力豊かなアニメーションを作成できます
