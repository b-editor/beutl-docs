---

ソースオブジェクトはタイムラインの要素に配置される描画オブジェクトです。
画像、動画、図形、テキスト、3Dオブジェクトなど、さまざまな種類があります。

要素の追加方法については[要素の追加](../get-started/4.add-element.md)をご覧ください。

## 共通プロパティ

ほとんどのソースオブジェクトは以下の共通プロパティを持ちます。

| プロパティ | 説明 |
| --- | --- |
| トランスフォーム | 移動、回転、スケールなどの変換 |
| 水平方向の位置合わせ | 水平方向のアラインメント |
| 垂直方向の位置合わせ | 垂直方向のアラインメント |
| 変換の原点 | 変換の基準点 |
| 画像フィルター | 適用するエフェクト |
| ブレンドモード | ブレンドモード |
| 不透明度 | 不透明度 |

## メディアソース

### 画像
画像ファイルを読み込んで表示します。

| プロパティ | 説明 |
| --- | --- |
| ソース | 画像ファイルのパス |

### 動画
動画ファイルを読み込んで再生します。

| プロパティ | 説明 |
| --- | --- |
| ソース | 動画ファイルのパス |
| オフセット位置 | 再生開始位置のオフセット |
| スピード | 再生速度 (%)。デフォルト: 100 |
| ループ | ループ再生 |

### サウンド
音声ファイルを読み込んで再生します。

| プロパティ | 説明 |
| --- | --- |
| ソース | 音声ファイルのパス |
| オフセット位置 | 再生開始位置のオフセット |
| ゲイン | 音量 (%)。デフォルト: 100 |
| スピード | 再生速度 (%)。デフォルト: 100 |
| 音声エフェクト | オーディオエフェクト |

## テキスト

### テキスト
テキストを描画します。フォント、サイズ、スタイルなどを設定できます。

| プロパティ | 説明 |
| --- | --- |
| テキスト | 表示するテキスト |

| 塗りつぶし | 塗りつぶし。デフォルト: 白 |

## 3Dオブジェクト

Beutlでは3Dオブジェクトを使った合成も可能です。
3Dオブジェクトを使用するには、まず __3Dシーン__ を作成し、その中に3Dオブジェクトやライトを配置します。

詳細は[3Dシーンの構成](../advanced/7.3d-scene.md)をご覧ください。

### 3Dシーン
3Dオブジェクトを配置するための空間です。カメラ、環境光、背景色などを設定します。

| プロパティ | 説明 |
| --- | --- |
| カメラ | カメラ |
| 環境光の色 | 環境光の色。デフォルト: 白 |
| 環境光の強度 | 環境光の強さ。デフォルト: 0.1 |
| レンダリング幅 | レンダリング解像度 (幅)。デフォルト: 1920 |
| レンダリング高さ | レンダリング解像度 (高さ)。デフォルト: 1080 |
| 背景色 | 背景色。デフォルト: 黒 |
