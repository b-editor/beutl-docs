# トランスフォーム

トランスフォームは、オブジェクトの位置、サイズ、回転、歪みなどを制御するための機能です。複数のトランスフォームを組み合わせることで、複雑な変形を実現できます。

## トランスフォームの概要

トランスフォームは、オブジェクトの視覚的な配置と変形を制御します。Beutlでは、以下のトランスフォームタイプが利用可能です：

- 移動
- スケール
- 回転
- 歪み
- 回転3D
- 行列変形
- グループ

これらのトランスフォームは、個別に使用することも、グループトランスフォームで組み合わせることもできます。

## 移動

オブジェクトの位置を変更します。

### プロパティ

| プロパティ | 説明 | デフォルト値 |
|-----------|------|-------------|
| X | 水平方向の移動距離（ピクセル） | 0 |
| Y | 垂直方向の移動距離（ピクセル） | 0 |

## スケール

オブジェクトのサイズを変更します。

### プロパティ

| プロパティ | 説明 | デフォルト値 |
|-----------|------|-------------|
| スケール | 全体のスケール倍率 | 100% |
| X拡大率 | 水平方向のスケール倍率 | 100% |
| Y拡大率 | 垂直方向のスケール倍率 | 100% |

### 使い方

- **スケール**プロパティは、XとYの両方に同時に適用されます
- **X拡大率**と**Y拡大率**を個別に設定することで、オブジェクトを引き伸ばしたり圧縮したりできます
- 例：スケール100%, X拡大率200%, Y拡大率50% → 横に2倍、縦に0.5倍

## 回転

オブジェクトを回転させます。

### プロパティ

| プロパティ | 説明 | デフォルト値 |
|-----------|------|-------------|
| 回転角度 | 時計回りの回転角度（度） | 0° |

### 注意事項

- 回転の中心点は、オブジェクトの中心です
- 負の値で反時計回りに回転します

## 歪み

オブジェクトを斜めに傾けます（シアー変形）。

### プロパティ

| プロパティ | 説明 | デフォルト値 |
|-----------|------|-------------|
| X傾き | 水平方向の傾き角度（度） | 0° |
| Y傾き | 垂直方向の傾き角度（度） | 0° |

### 使用例

- **X傾き**：オブジェクトを左右に傾ける（イタリック体のような効果）
- **Y傾き**：オブジェクトを上下に傾ける

## 回転3D

3D空間でオブジェクトを回転させます。

### プロパティ

| プロパティ | 説明 | デフォルト値 |
|-----------|------|-------------|
| X回転 | X軸周りの回転角度（度） | 0° |
| Y回転 | Y軸周りの回転角度（度） | 0° |
| Z回転 | Z軸周りの回転角度（度） | 0° |
| 中心X | 回転の中心点のX座標（ピクセル） | オブジェクト中心 |
| 中心Y | 回転の中心点のY座標（ピクセル） | オブジェクト中心 |
| 中心Z | 回転の中心点のZ座標（ピクセル） | 0 |
| 深度 | 透視投影の強さ | 500 |

### 軸の説明

- **X軸回転**：オブジェクトを水平軸で回転（前後に傾ける）
- **Y軸回転**：オブジェクトを垂直軸で回転（左右に向きを変える）
- **Z軸回転**：オブジェクトを奥行き軸で回転（画面上で回転）

### 深度について

深度パラメータは、3D回転の遠近感の強さを制御します：

- 値が小さいほど、遠近感が強くなります
- 値が大きいほど、遠近感が弱くなります
- デフォルトの500が一般的に自然な見た目を提供します

## 行列変形

変形行列を直接指定して、任意の変形を行います。

### プロパティ

| プロパティ | 説明 |
|-----------|------|
| 行列 | 3x3または4x4の変形行列 |

### 使用例

高度な変形や、他のソフトウェアから変形行列をインポートする場合に使用します。一般的なユーザーは、他のトランスフォームタイプを使用することをお勧めします。

## グループ

複数のトランスフォームを組み合わせて、1つのトランスフォームとして扱います。

### 特徴

- 複数のトランスフォームを順番に適用できます
- トランスフォームの適用順序を制御できます
- 複雑な変形を管理しやすくなります

### 使い方

1. グループトランスフォームを作成
2. グループ内に他のトランスフォームを追加
3. トランスフォームの順序を調整

### 適用順序の重要性

トランスフォームの適用順序によって、結果が異なります：

**例1：移動 → 回転**
1. オブジェクトを右に100ピクセル移動
2. その後、中心で45度回転

**例2：回転 → 移動**
1. オブジェクトを中心で45度回転
2. その後、右に100ピクセル移動

これらは異なる結果になります。グループトランスフォームを使用することで、この順序を明示的に制御できます。

## トランスフォームの組み合わせ例

### カードがめくれるアニメーション

1. **回転3D**を使用
2. Y軸回転を0度から180度にアニメーション
3. 中心Xをカードの左端に設定
4. 深度を適切に調整

### バウンスしながら拡大するテキスト

1. **グループ**トランスフォームを作成
2. **スケール**を追加：0%から100%にアニメーション、イージングに「バウンスイーズアウト」を使用
3. **移動**を追加：Y方向に-50から0にアニメーション

### 遠近感のあるスライドイン

1. **グループ**トランスフォームを作成
2. **回転3D**を追加：Y軸回転を-60度から0度にアニメーション
3. **移動**を追加：X方向に-200から0にアニメーション
4. イージングに「三次イーズアウト」を使用

## ヒント

- トランスフォームはアニメーション可能です。キーフレームを設定して、時間経過による変化を作成できます
- 複数のトランスフォームを使用する場合、グループトランスフォームで管理すると便利です
- 3D回転を使用する場合、適切な深度設定が重要です
- スケールと移動を組み合わせることで、ズームインやズームアウトの効果を作成できます
- 回転の中心点を変更することで、異なる回転効果を得られます
