Beutlでは多くの操作をキーボードショートカットで行うことができます。
ここではデフォルトのキーボードショートカットを一覧で紹介します。

## ファイル・プロジェクト操作

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 新しいプロジェクトを作成 | Ctrl + Shift + N | Cmd + Shift + N |
| 新しいシーンを作成 | Ctrl + N | Cmd + N |
| プロジェクトを開く | Ctrl + Shift + O | Cmd + Shift + O |
| ファイルを開く | Ctrl + O | Cmd + O |
| 保存 | Ctrl + S | Cmd + S |
| すべて保存 | Ctrl + Shift + S | Cmd + Shift + S |
| プロジェクトを閉じる | Ctrl + Shift + F4 | Cmd + Shift + W |
| 元に戻す | Ctrl + Z | Cmd + Z |
| やり直す | Ctrl + Y | Cmd + Shift + Z |
| 終了 | Alt + F4 | Cmd + Q |

## 再生操作

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 再生 / 一時停止 | Space | Space |
| 次のフレームへ | → (右矢印) | → (右矢印) |
| 前のフレームへ | ← (左矢印) | ← (左矢印) |
| 先頭へ移動 | Home | Cmd + ← |
| 末尾へ移動 | End | Cmd + → |

## タイムライン・要素の編集

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| コピー | Ctrl + C | Cmd + C |
| 貼り付け | Ctrl + V | Cmd + V |
| 切り取り | Ctrl + X | Cmd + X |
| 名前の変更 | F2 | Enter |
| 要素の除外 | Delete | Backspace |
| 要素の削除 | Ctrl + Delete | Cmd + Backspace |
| 現在のフレームで分割 | Ctrl + K | Cmd + K |
| 開始時間を設定 | [ | [ |
| 終了時間を設定 | ] | ] |
| グループの切り替え | Ctrl + G | Cmd + G |

> [!TIP]
> __要素の除外__ は要素をタイムラインから取り除きますが、プロジェクトからは削除しません。
> __要素の削除__ は要素を完全に削除します。

## キーボードショートカットのカスタマイズ

キーボードショートカットは設定画面から変更できます。

1. メニューバーの設定を開きます。
2. __キーマップ__ のページに移動します。
3. 変更したいコマンドを見つけ、新しいキーの組み合わせを設定します。

カスタマイズした設定は `keymap.json` に保存されます。
