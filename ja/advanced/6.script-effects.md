# スクリプトエフェクト

Beutlでは、SKSLやGLSLを使用してカスタムエフェクトを作成できます。これにより、標準のエフェクトでは実現できない高度な視覚効果を実装することができます。

## SKSLスクリプトエフェクト

SKSLは、Skiaのシェーダー言語です。プラットフォームを問わず動作し、Beutlの標準的なスクリプトエフェクトとして使用できます。

### 利用可能な変数

SKSLスクリプトエフェクトでは、以下の変数が利用可能です：

- `src` - 入力画像（シェーダー）
- `progress` - 0.0から1.0の進捗値
- `duration` - エフェクトの長さ（秒）
- `time` - 現在の時間（秒）
- `width` / `height` - 描画サイズ（ピクセル）
- `iResolution` - 解像度（vec2型）
- `iTime` - 経過時間（秒）

### デフォルトシェーダーテンプレート

```glsl
uniform shader src;
uniform float progress;
uniform float duration;
uniform float time;
uniform float width;
uniform float height;

half4 main(float2 coord) {
    // coord: 現在のピクセル座標
    // src: 入力画像のサンプリング

    return src.eval(coord);
}
```

### 使用例

グレースケールエフェクトの例：

```glsl
uniform shader src;

half4 main(float2 coord) {
    half4 color = src.eval(coord);
    float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
    return half4(gray, gray, gray, color.a);
}
```

波打つエフェクトの例：

```glsl
uniform shader src;
uniform float time;
uniform float width;

half4 main(float2 coord) {
    float2 newCoord = coord;
    newCoord.x += sin(coord.y / 10.0 + time * 2.0) * 5.0;
    return src.eval(newCoord);
}
```

## GLSLスクリプトエフェクト

GLSLスクリプトエフェクトは、Vulkanバックエンドを使用したGLSLシェーダーです。3Dレンダリングに対応した環境でのみ動作します。

### 利用可能な変数

GLSLスクリプトエフェクトでは、push constantsとして以下の変数が利用可能です：

- `progress` - 0.0から1.0の進捗値
- `duration` - エフェクトの長さ（秒）
- `time` - 現在の時間（秒）
- `width` / `height` - 描画サイズ（ピクセル）
- `iResolution` - 解像度
- `iTime` - 経過時間（秒）

### デフォルトシェーダーテンプレート

```glsl
#version 450

layout(location = 0) in vec2 fragCoord;
layout(location = 0) out vec4 fragColor;

layout(binding = 0) uniform sampler2D src;

layout(push_constant) uniform PushConstants {
    float progress;
    float duration;
    float time;
    float width;
    float height;
} constants;

void main() {
    vec2 uv = fragCoord / vec2(constants.width, constants.height);
    fragColor = texture(src, uv);
}
```

### 使用例

色反転エフェクトの例：

```glsl
#version 450

layout(location = 0) in vec2 fragCoord;
layout(location = 0) out vec4 fragColor;

layout(binding = 0) uniform sampler2D src;

layout(push_constant) uniform PushConstants {
    float progress;
    float duration;
    float time;
    float width;
    float height;
} constants;

void main() {
    vec2 uv = fragCoord / vec2(constants.width, constants.height);
    vec4 color = texture(src, uv);
    fragColor = vec4(1.0 - color.rgb, color.a);
}
```

## 注意事項

- SKSLスクリプトエフェクトは、すべての環境で動作します。
- GLSLスクリプトエフェクトは、Vulkanバックエンドが有効な環境でのみ動作します。
- シェーダーのコンパイルエラーが発生した場合、エフェクトは適用されません。
- 複雑な計算を行うシェーダーは、パフォーマンスに影響を与える可能性があります。
