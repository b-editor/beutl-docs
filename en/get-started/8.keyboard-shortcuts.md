Beutl provides many keyboard shortcuts to help you work efficiently.
This page lists the default keyboard shortcuts.

## File & Project

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Create New Project | Ctrl + Shift + N | Cmd + Shift + N |
| Create New Scene | Ctrl + N | Cmd + N |
| Open Project | Ctrl + Shift + O | Cmd + Shift + O |
| Open File | Ctrl + O | Cmd + O |
| Save | Ctrl + S | Cmd + S |
| Save All | Ctrl + Shift + S | Cmd + Shift + S |
| Close Project | Ctrl + Shift + F4 | Cmd + Shift + W |
| Undo | Ctrl + Z | Cmd + Z |
| Redo | Ctrl + Y | Cmd + Shift + Z |
| Exit | Alt + F4 | Cmd + Q |

## Playback

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Play / Pause | Space | Space |
| Next Frame | Right Arrow | Right Arrow |
| Previous Frame | Left Arrow | Left Arrow |
| Seek to Start | Home | Cmd + Left |
| Seek to End | End | Cmd + Right |

## Timeline & Element Editing

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Copy | Ctrl + C | Cmd + C |
| Paste | Ctrl + V | Cmd + V |
| Cut | Ctrl + X | Cmd + X |
| Rename | F2 | Enter |
| Exclude Element | Delete | Backspace |
| Delete Element | Ctrl + Delete | Cmd + Backspace |
| Split at Current Frame | Ctrl + K | Cmd + K |
| Set Start Time | [ | [ |
| Set End Time | ] | ] |
| Toggle Group | Ctrl + G | Cmd + G |

> [!TIP]
> __Exclude Element__ removes the element from the timeline but does not delete it from the project.
> __Delete Element__ permanently removes the element.

## Customizing Keyboard Shortcuts

You can customize keyboard shortcuts from the settings.

1. Open the settings from the menu bar.
2. Navigate to the __Key Map__ page.
3. Find the command you want to change and set a new key combination.

Custom settings are saved to `keymap.json`.
