# Animation & Easing Functions

Easing functions control the rate of change in animations, making them feel more natural and dynamic. Instead of linear motion, easing functions can create acceleration, deceleration, bouncing, and other effects.

## Overview

Beutl provides 32 built-in easing functions organized into categories. Each category (except Linear and Spline) includes three variations:

- **In** - Acceleration from zero velocity
- **Out** - Deceleration to zero velocity
- **InOut** - Acceleration until halfway, then deceleration

## Linear

| Name | Description |
|------|-------------|
| Linear | Constant speed with no acceleration or deceleration |

## Sine

| Name | Description |
|------|-------------|
| Sine In | Gentle acceleration using sine curve |
| Sine Out | Gentle deceleration using sine curve |
| Sine InOut | Gentle acceleration then deceleration using sine curve |

## Quadratic

| Name | Description |
|------|-------------|
| Quadratic In | Acceleration following a quadratic curve (power of 2) |
| Quadratic Out | Deceleration following a quadratic curve (power of 2) |
| Quadratic InOut | Acceleration then deceleration using quadratic curve |

## Cubic

| Name | Description |
|------|-------------|
| Cubic In | Stronger acceleration following a cubic curve (power of 3) |
| Cubic Out | Stronger deceleration following a cubic curve (power of 3) |
| Cubic InOut | Acceleration then deceleration using cubic curve |

## Quartic

| Name | Description |
|------|-------------|
| Quartic In | Very strong acceleration following a quartic curve (power of 4) |
| Quartic Out | Very strong deceleration following a quartic curve (power of 4) |
| Quartic InOut | Acceleration then deceleration using quartic curve |

## Quintic

| Name | Description |
|------|-------------|
| Quintic In | Extremely strong acceleration following a quintic curve (power of 5) |
| Quintic Out | Extremely strong deceleration following a quintic curve (power of 5) |
| Quintic InOut | Acceleration then deceleration using quintic curve |

## Exponential

| Name | Description |
|------|-------------|
| Exponential In | Very sharp acceleration using exponential function |
| Exponential Out | Very sharp deceleration using exponential function |
| Exponential InOut | Sharp acceleration then deceleration using exponential function |

## Circular

| Name | Description |
|------|-------------|
| Circular In | Acceleration following a circular curve |
| Circular Out | Deceleration following a circular curve |
| Circular InOut | Acceleration then deceleration using circular curve |

## Back

| Name | Description |
|------|-------------|
| Back In | Slight backward motion before accelerating forward (anticipation) |
| Back Out | Overshoot the target then settle back (overshoot) |
| Back InOut | Anticipation at start, overshoot at end |

## Bounce

| Name | Description |
|------|-------------|
| Bounce In | Bouncing effect before reaching the start position |
| Bounce Out | Bouncing effect after reaching the end position |
| Bounce InOut | Bouncing at both start and end |

## Elastic

| Name | Description |
|------|-------------|
| Elastic In | Elastic spring-like motion before reaching start |
| Elastic Out | Elastic spring-like motion after reaching end |
| Elastic InOut | Elastic motion at both start and end |

## Spline

| Name | Description |
|------|-------------|
| Spline | Custom bezier curve easing with user-defined control points |

### Spline Easing

The Spline easing function allows you to create custom easing curves using bezier control points. You can define the curve by specifying two control points (P1 and P2) with X and Y coordinates.

- **P1** - First control point (x1, y1)
- **P2** - Second control point (x2, y2)

The curve starts at (0, 0) and ends at (1, 1), with the control points shaping the curve in between.

## Choosing an Easing Function

- **Natural motion**: Use Sine or Quadratic easing
- **Snappy animations**: Use Cubic, Quartic, or Quintic easing
- **Bouncy effects**: Use Bounce or Elastic easing
- **Anticipation/Overshoot**: Use Back easing
- **Custom timing**: Use Spline easing with custom control points
