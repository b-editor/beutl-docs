# Transforms

Transforms allow you to manipulate the position, size, rotation, and perspective of elements in your composition. Beutl provides several transform types that can be combined to create complex transformations.

## Overview

Transforms modify how elements are rendered without changing their underlying data. Multiple transforms can be combined using the Group transform to create complex effects.

## Transform Types

### Translate

Moves an element along the X and Y axes.

**Properties:**
- **X** - Horizontal offset in pixels
- **Y** - Vertical offset in pixels

### Scale

Resizes an element uniformly or non-uniformly.

**Properties:**
- **Scale** - Uniform scaling percentage (default: 100%)
- **Scale X** - Horizontal scaling percentage (default: 100%)
- **Scale Y** - Vertical scaling percentage (default: 100%)

When Scale is set, it affects both X and Y equally. Scale X and Scale Y allow independent control of each axis.

### Rotation

Rotates an element around its center point.

**Properties:**
- **Rotation** - Rotation angle in degrees (positive = clockwise, negative = counter-clockwise)

### Skew

Shears an element along the X or Y axis, creating a slanted appearance.

**Properties:**
- **Skew X** - Horizontal skew angle in degrees
- **Skew Y** - Vertical skew angle in degrees

### Rotation 3D

Rotates an element in 3D space with perspective projection.

**Properties:**
- **Rotation X** - Rotation around the X axis in degrees (pitch)
- **Rotation Y** - Rotation around the Y axis in degrees (yaw)
- **Rotation Z** - Rotation around the Z axis in degrees (roll)
- **Center X** - X coordinate of rotation pivot point
- **Center Y** - Y coordinate of rotation pivot point
- **Depth** - Perspective depth (default: 500)

The Depth property controls the strength of the perspective effect. Lower values create more dramatic perspective, while higher values create more subtle effects.

### Matrix Transform

Applies a custom transformation matrix directly.

**Properties:**
- **Matrix** - A 3x3 transformation matrix

This is an advanced option that allows complete control over the transformation. The matrix encodes translation, rotation, scale, and skew in a single mathematical structure.

### Group

Combines multiple transforms into a single transformation.

**Properties:**
- **Transforms** - A list of child transforms to apply in sequence

Transforms in a group are applied in order from first to last. The order matters - rotating then translating produces a different result than translating then rotating.

## Transform Order

When multiple transforms are applied (either through a Group or multiple transform layers), they are applied in sequence. The order of operations significantly affects the final result:

1. Scale
2. Rotation
3. Translate

This is the typical order for predictable results, but you can change it using the Group transform.

## Best Practices

- Use **Translate** for simple position changes
- Use **Scale** to resize elements proportionally, or Scale X/Y for non-uniform scaling
- Use **Rotation** for 2D rotation effects
- Use **Rotation 3D** when you need perspective and 3D effects
- Use **Group** to combine multiple transforms in a specific order
- Use **Matrix Transform** only when you need precise mathematical control

## Tips

- The center point of rotation can be changed in Rotation 3D
- Negative scale values create mirror effects
- Combining Skew X and Skew Y can create interesting distortion effects
- Use small Depth values (200-300) for dramatic 3D effects
- Use large Depth values (800-1000) for subtle 3D effects
