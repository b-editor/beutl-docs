# Supported Media Formats

Beutl supports a wide variety of media formats for both input and output. Media format support is provided through FFmpeg, which must be installed separately.

## Prerequisites

**IMPORTANT:** FFmpeg must be installed on your system for media import and export to work properly.

[See FFmpeg installation instructions →](/en/get-started/2.install-ffmpeg)

## Video Input Formats

Beutl can import the following video formats:

- `.avi` - Audio Video Interleave
- `.mov` - QuickTime Movie
- `.wmv` - Windows Media Video
- `.mp4` - MPEG-4 Part 14
- `.webm` - WebM
- `.mkv` - Matroska Video
- `.flv` - Flash Video
- `.264` - Raw H.264 Video
- `.mpeg` - MPEG Program Stream
- `.ts` - MPEG Transport Stream
- `.mts` - MPEG Transport Stream (AVCHD)
- `.m2ts` - Blu-ray MPEG-2 Transport Stream

## Audio Input Formats

Beutl can import the following audio formats:

- `.mp3` - MPEG Audio Layer 3
- `.ogg` - Ogg Vorbis
- `.wav` - Waveform Audio File
- `.aac` - Advanced Audio Coding
- `.wma` - Windows Media Audio
- `.m4a` - MPEG-4 Audio
- `.webm` - WebM Audio
- `.opus` - Opus Audio

## Video Output Formats

Beutl can export to the following video formats:

- `.mp4` - MPEG-4 Part 14 (recommended for general use)
- `.wmv` - Windows Media Video
- `.avi` - Audio Video Interleave
- `.webm` - WebM (recommended for web use)
- `.3gp` - 3GPP Mobile Video
- `.3g2` - 3GPP2 Mobile Video
- `.flv` - Flash Video
- `.mkv` - Matroska Video (recommended for high quality)
- `.mov` - QuickTime Movie (recommended for editing workflows)
- `.ogv` - Ogg Video

## Audio Output Formats

Beutl can export to the following audio formats:

- `.wav` - Waveform Audio File (uncompressed)
- `.mp3` - MPEG Audio Layer 3 (compressed)

## Codec Support

The actual codecs available for encoding and decoding depend on your FFmpeg installation. Common codecs include:

### Video Codecs
- H.264 (AVC)
- H.265 (HEVC)
- VP8 / VP9
- AV1
- ProRes
- DNxHD

### Audio Codecs
- AAC
- MP3
- Opus
- Vorbis
- PCM (uncompressed)

## Format Recommendations

### For General Use
- **Video:** MP4 with H.264 codec (good balance of quality and compatibility)
- **Audio:** MP3 (wide compatibility) or AAC (better quality at same bitrate)

### For Web
- **Video:** WebM with VP9 codec (efficient compression, open format)
- **Audio:** Opus (best quality at low bitrates)

### For Editing/Archival
- **Video:** MKV or MOV with high-quality codec (ProRes, DNxHD)
- **Audio:** WAV (lossless, uncompressed)

### For Mobile
- **Video:** MP4 with H.264 codec
- **Audio:** AAC

## Troubleshooting

If a format is not working:

1. Verify FFmpeg is properly installed
2. Check that your FFmpeg installation includes the required codec
3. Try converting the file to a more common format (like MP4)
4. Update FFmpeg to the latest version

## Notes

- Import support depends on the codecs available in your FFmpeg installation
- Some proprietary formats may require additional FFmpeg configuration
- Hardware acceleration support varies by platform and FFmpeg build
- Alpha channel support is available in formats like WebM and MOV (with ProRes 4444)
