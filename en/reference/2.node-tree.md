title: Node Tree

Beutl includes a node-based compositing system that allows you to build rendering pipelines visually using a node graph, as an alternative to source operations.
In the node tree, data flow is defined by connecting sockets (inputs and outputs) between nodes.

## Basic Concepts

### Nodes and Sockets

Each node has **input sockets** and **output sockets**.

- **Output sockets** send data. A single output socket can connect to multiple input sockets.
- **Input sockets** receive data. A single input socket accepts a connection from only one output socket.

Sockets are connected based on type. If types differ, automatic type conversion is attempted.

### Data Flow

The node tree is evaluated in the following order:

1. **PreEvaluate** - Each node sets default values
2. **Evaluate** - Each node processes data
3. **PostEvaluate** - Data is distributed from output sockets to connected input sockets

The evaluation order is automatically determined by topological sorting based on node connections.

## Special Nodes

### LayerInputNode
Exposes layer properties as output sockets.
If an animation is set, the animated value at the current time is output.
For static properties, the value is output as-is.

This node serves as the starting point of data flow in the node tree.

### OutputNode
The terminal node of the node tree. Receives a `RenderNode` as input and passes it to the rendering pipeline as a drawable object.

Every node tree requires at least one output node.

### GroupNode
Groups multiple nodes together to create reusable subgraphs.
Group inputs and outputs can be added dynamically, encapsulating the internal node graph.

## Registering Nodes

When developing extensions, you can register custom nodes using `NodeRegistry`.

```csharp
// Register a single node
NodeRegistry.RegisterNode<MyNode>("Display Name", Color.FromRgb(100, 150, 200));

// Register with categories
NodeRegistry.RegisterNodes("Category Name")
    .Add<Node1>("Node 1")
    .Add<Node2>("Node 2")
    .AddGroup("Subcategory", helper =>
        helper.Add<Node3>("Node 3"))
    .Register();
```
