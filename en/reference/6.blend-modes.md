# Blend Modes

Blend modes determine how layers combine with the layers beneath them. They control the mathematical operation used to merge pixel colors, allowing you to create various visual effects.

## Overview

Beutl supports 29 blend modes based on the Porter-Duff compositing operations and additional color blend modes. The blend mode affects how the source layer (top) interacts with the destination layer (bottom).

## Available Blend Modes

| Name | Description |
|------|-------------|
| Clear | Clears the destination, making it transparent |
| Src | Shows only the source layer, ignoring the destination |
| Dst | Shows only the destination layer, ignoring the source |
| Src Over | Normal blending - source layer appears over destination (default) |
| Dst Over | Destination layer appears over source |
| Src In | Shows source only where destination is opaque |
| Dst In | Shows destination only where source is opaque |
| Src Out | Shows source only where destination is transparent |
| Dst Out | Shows destination only where source is transparent |
| Src ATop | Source replaces destination where destination is opaque |
| Dst ATop | Destination replaces source where source is opaque |
| Xor | Shows areas where only one layer is opaque (exclusive or) |
| Plus | Adds the color values of source and destination |
| Modulate | Multiplies the color values and divides by maximum value |
| Screen | Inverts, multiplies, then inverts again (lightens) |
| Overlay | Combines Multiply and Screen based on destination brightness |
| Darken | Selects the darker color from source and destination |
| Lighten | Selects the lighter color from source and destination |
| Color Dodge | Brightens destination based on source color |
| Color Burn | Darkens destination based on source color |
| Hard Light | Like Overlay but based on source brightness instead of destination |
| Soft Light | Similar to Hard Light but with softer effect |
| Difference | Subtracts the darker color from the lighter color |
| Exclusion | Similar to Difference but with lower contrast |
| Multiply | Multiplies color values (darkens) |
| Hue | Uses hue from source, saturation and luminosity from destination |
| Saturation | Uses saturation from source, hue and luminosity from destination |
| Color | Uses hue and saturation from source, luminosity from destination |
| Luminosity | Uses luminosity from source, hue and saturation from destination |

## Blend Mode Categories

### Compositing Modes (Porter-Duff)
These modes control how the alpha channels interact:
- Clear, Src, Dst, Src Over, Dst Over
- Src In, Dst In, Src Out, Dst Out
- Src ATop, Dst ATop, Xor

### Darkening Modes
These modes make the result darker:
- Darken, Multiply, Color Burn

### Lightening Modes
These modes make the result lighter:
- Lighten, Screen, Color Dodge

### Contrast Modes
These modes affect contrast:
- Overlay, Hard Light, Soft Light

### Inversion Modes
These modes create inverted effects:
- Difference, Exclusion

### Component Modes
These modes mix color components:
- Hue, Saturation, Color, Luminosity

### Mathematical Modes
These modes perform mathematical operations:
- Plus, Modulate

## Common Use Cases

- **Src Over** - Normal layer stacking (default)
- **Multiply** - Creating shadows and darkening effects
- **Screen** - Creating light effects and glows
- **Overlay** - Adding texture while preserving highlights and shadows
- **Color Dodge** - Creating bright, intense highlights
- **Color Burn** - Creating deep shadows with saturated colors
- **Difference** - Creating artistic inversion effects
- **Hue/Saturation/Color** - Color grading and adjustment
- **Src In** - Using one layer as a mask for another

## Tips

- Experiment with different blend modes to achieve desired effects
- Use Multiply for realistic shadows
- Use Screen for adding light and glow effects
- Use Color mode to recolor elements while preserving detail
- Combine blend modes with opacity for fine control
- Some blend modes work best with specific types of content
