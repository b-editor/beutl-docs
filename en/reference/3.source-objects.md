Source objects are drawing objects placed on timeline elements.
They include images, videos, shapes, text, 3D objects, and more.

For how to add elements, see [Adding Elements](../get-started/4.add-element.md).

## Common Properties

Most source objects share the following common properties.

| Property | Type | Description |
| --- | --- | --- |
| Transform | TransformGroup | Translation, rotation, scale, etc. |
| AlignmentX | AlignmentX | Horizontal alignment |
| AlignmentY | AlignmentY | Vertical alignment |
| TransformOrigin | RelativePoint | Transform origin point |
| FilterEffect | FilterEffectGroup | Effects to apply |
| BlendMode | BlendMode | Blend mode |
| Opacity | float | Opacity |

## Media Sources

### Image (SourceImage)
Loads and displays image files.

| Property | Type | Description |
| --- | --- | --- |
| Source | FileInfo | Image file path |

### Video (SourceVideo)
Loads and plays video files.

| Property | Type | Description |
| --- | --- | --- |
| Source | FileInfo | Video file path |
| OffsetPosition | TimeSpan | Playback start offset |
| Speed | float | Playback speed (%). Default: 100 |
| IsLoop | bool | Loop playback |

### Sound (SourceSound)
Loads and plays audio files.

| Property | Type | Description |
| --- | --- | --- |
| Source | FileInfo | Audio file path |
| OffsetPosition | TimeSpan | Playback start offset |
| Gain | float | Volume (%). Default: 100 |
| Speed | float | Playback speed (%). Default: 100 |
| Effect | AudioEffectGroup | Audio effects |

## 2D Shapes

### Rectangle (Rect)
Draws a rectangle.

| Property | Type | Description |
| --- | --- | --- |
| Width | float | Width. Default: 100 |
| Height | float | Height. Default: 100 |
| Pen | Pen | Stroke |
| Fill | Brush | Fill color. Default: White |

### Rounded Rectangle (RoundedRect)
Draws a rectangle with rounded corners.

| Property | Type | Description |
| --- | --- | --- |
| Width | float | Width. Default: 100 |
| Height | float | Height. Default: 100 |
| CornerRadius | CornerRadius | Corner radius. Default: 25 |
| Smoothing | float | Smoothing. Default: 0 |
| Pen | Pen | Stroke |
| Fill | Brush | Fill color. Default: White |

### Ellipse
Draws an ellipse or circle.

| Property | Type | Description |
| --- | --- | --- |
| Width | float | Width. Default: 100 |
| Height | float | Height. Default: 100 |
| Pen | Pen | Stroke |
| Fill | Brush | Fill color. Default: White |

### Geometry
Draws custom path geometry. Use to create freeform shapes.

| Property | Type | Description |
| --- | --- | --- |
| Data | PathGeometry | Path data |
| Pen | Pen | Stroke |
| Fill | Brush | Fill color. Default: White |

## Text

### TextBlock
Renders text with configurable font, size, and style.

| Property | Type | Description |
| --- | --- | --- |
| Text | string | Text to display |
| Size | float | Font size. Default: 24 |
| FontFamily | FontFamily | Font family |
| FontStyle | FontStyle | Font style (Normal, Italic) |
| FontWeight | FontWeight | Font weight (Regular, Bold, etc.) |
| Spacing | float | Character spacing. Default: 0 |
| SplitByCharacters | bool | Split into individual characters |
| Pen | Pen | Stroke |
| Fill | Brush | Fill color. Default: White |

## Other 2D Objects

### Backdrop (SourceBackdrop)
Captures the rendered result of layers behind it. Useful for applying effects to the background.

| Property | Type | Description |
| --- | --- | --- |
| Clear | bool | Clear the rendering |

### Time Controller (DrawableTimeController)
Controls the playback timing of other drawable objects.

| Property | Type | Description |
| --- | --- | --- |
| OffsetPosition | TimeSpan | Start time offset |
| Speed | float | Playback speed |
| AdjustTimeRange | bool | Adjust time range |
| FrameRate | float | Frame rate |
| Reverse | bool | Reverse playback |

## 3D Objects

Beutl supports compositing with 3D objects.
To use 3D objects, first create a __3D Scene__, then place 3D objects and lights within it.

### 3D Scene (Scene3D)
The space for placing 3D objects. Configure the camera, ambient light, and background color.

| Property | Type | Description |
| --- | --- | --- |
| Camera | PerspectiveCamera | Camera |
| AmbientColor | Color | Ambient light color. Default: White |
| AmbientIntensity | float | Ambient light intensity. Default: 0.1 |
| RenderWidth | float | Render resolution (width). Default: 1920 |
| RenderHeight | float | Render resolution (height). Default: 1080 |
| BackgroundColor | Color | Background color. Default: Black |

### Cube (Cube3D)
Draws a 3D cube.

| Property | Type | Description |
| --- | --- | --- |
| Width | float | Width |
| Height | float | Height |
| Depth | float | Depth |
| Position | Vector3 | 3D position |
| Rotation | Vector3 | Rotation |
| Scale | Vector3 | Scale |
| Material | Material | Material |
| CastShadows | bool | Cast shadows |
| ReceiveShadows | bool | Receive shadows |

### Sphere (Sphere3D)
Draws a 3D sphere.

| Property | Type | Description |

| Rotation | Vector3 | Rotation |
| Scale | Vector3 | Scale |
| Material | Material | Material |
| CastShadows | bool | Cast shadows |
| ReceiveShadows | bool | Receive shadows |

### Plane (Plane3D)

| Property | Type | Description |

## 3D Lights

Light sources for illuminating 3D scenes.

### Directional Light (DirectionalLight3D)

| Property | Type | Description |
| --- | --- | --- |
| Direction | Vector3 | Light direction |
| Color | Color | Light color |
| Intensity | float | Light intensity |
| CastsShadow | bool | Generate shadows |
| ShadowDistance | float | Shadow projection distance |
| ShadowMapSize | int | Shadow map resolution |
| ShadowBias | float | Shadow bias |
| ShadowNormalBias | float | Normal bias |
| ShadowStrength | float | Shadow strength |

### Point Light (PointLight3D)

| Range | float | Light range |
| ConstantAttenuation | float | Constant attenuation |
| LinearAttenuation | float | Linear attenuation |
| QuadraticAttenuation | float | Quadratic attenuation |
