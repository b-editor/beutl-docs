Beutl provides a wide range of effects that can be applied to drawing objects.
This page lists all available effects organized by category.

For how to add effects, see [Editing Elements](../get-started/5.edit-element.md).

## Blur & Mosaic

### Blur
Applies Gaussian blur.

| Property | Description |
| --- | --- |
| Sigma | Blur strength (X, Y) |

### CvBlur (OpenCV Blur)
Uniform blur using OpenCV.

| Property | Description |
| --- | --- |
| Kernel Size | Blur range |
| Fix Image Size | Match the output image size to the original |

### CvGaussianBlur (OpenCV Gaussian Blur)
Gaussian blur using OpenCV.

| Property | Description |
| --- | --- |
| Kernel Size | Blur range |
| Sigma | Blur strength |
| Fix Image Size | Match the output image size to the original |

### CvMedianBlur (OpenCV Median Blur)
Median blur using OpenCV. Effective for noise removal.

| Property | Description |
| --- | --- |
| Kernel Size | Blur range |
| Fix Image Size | Match the output image size to the original |

### Mosaic
Pixelates the image (mosaic processing).

| Property | Description |
| --- | --- |
| Tile Size | Tile size (width, height). Default: 10x10 |
| Origin | Mosaic origin. Default: Center |

## Color Correction

### Brightness
Adjusts image brightness.

| Property | Description |
| --- | --- |
| Amount | Brightness percentage. Default: 100 |

### Saturate
Adjusts color saturation.

| Property | Description |
| --- | --- |
| Amount | Saturation percentage. Default: 100 |

### Hue Rotate
Rotates hue by the specified angle.

| Property | Description |
| --- | --- |
| Angle | Rotation angle (degrees) |

### Invert
Inverts image colors.

| Property | Description |
| --- | --- |
| Amount | Inversion strength (0-100). Default: 100 |
| Exclude Alpha Channel | Disable alpha channel inversion. Default: On |

### Negaposi
Controls color inversion per RGB channel.

| Property | Description |
| --- | --- |
| Red | Red channel value |
| Green | Green channel value |
| Blue | Blue channel value |
| Strength | Effect strength (0-100). Default: 100 |

### Gamma
Applies gamma correction to adjust tonal range.

| Property | Description |
| --- | --- |
| Amount | Gamma value (1-300). Default: 100 |
| Strength | Effect strength (0-100). Default: 100 |

### High Contrast
Increases contrast.

| Property | Description |
| --- | --- |
| Grayscale | Convert to grayscale. Default: Off |
| Invert Style | Inversion style. Default: No Invert |
| Contrast | Contrast amount |

### Threshold
Converts image to binary (black and white).

| Property | Description |
| --- | --- |
| Amount | Threshold value (0-100). Default: 50 |
| Smoothing | Boundary smoothness (0-100). Default: 0 |
| Strength | Effect strength (0-100). Default: 100 |

## Color Grading

### Color Grading
Professional color grading using the Lift-Gamma-Gain model with temperature controls and HSV adjustments.

| Property | Description |
| --- | --- |
| Temperature | Color temperature (-100 to 100) |
| Tint | Color tint (-100 to 100) |
| Exposure | Exposure (-5 to 5) |
| Contrast | Contrast (-100 to 100) |
| Contrast Pivot | Contrast pivot (0 to 1). Default: 0.5 |
| Saturation | Saturation (-100 to 100) |
| Vibrance | Vibrance (-100 to 100) |
| Hue | Hue (-180 to 180) |
| Low Range | Shadow range (0 to 100). Default: 40 |
| High Range | Highlight range (0 to 100). Default: 60 |
| Shadows | Shadow color adjustment |
| Midtones | Midtone color adjustment |
| Highlights | Highlight color adjustment |
| Lift | Lift (shadow adjustment) |
| Gamma | Gamma (midtone adjustment) |
| Gain | Gain (highlight adjustment) |
| Offset | Offset (overall adjustment) |

### Curves
Detailed color correction using per-channel input/output curves.

| Property | Description |
| --- | --- |
| Custom (RGB) | Master curve |
| Red Curve | Red channel curve |
| Green Curve | Green channel curve |
| Blue Curve | Blue channel curve |
| Hue vs Hue | Hue-based hue adjustment |
| Hue vs Saturation | Hue-based saturation adjustment |
| Hue vs Luminance | Hue-based luminance adjustment |
| Luminance vs Saturation | Luminance-based saturation adjustment |
| Saturation vs Saturation | Saturation-based saturation adjustment |

### LUT (Cube File)
Applies color transformation using 3D LUT (Look-Up Table) files. Supports `.cube` files.

| Property | Description |
| --- | --- |
| Source | LUT file |
| Strength | LUT application strength (0-100). Default: 100 |

### Lighting
Applies multiplicative and additive color adjustments.

| Property | Description |
| --- | --- |
| Multiplication | Multiply color. Default: White |
| Addition | Add color. Default: Transparent |

## Shadows

### Drop Shadow
Renders a blurred shadow outside the object.

| Property | Description |
| --- | --- |
| Position | Shadow offset position |
| Sigma | Blur strength (X, Y) |
| Color | Shadow color |
| Shadow Only | Show shadow only. Default: Off |

### Inner Shadow
Renders a blurred shadow inside the object boundaries.

| Property | Description |
| --- | --- |
| Position | Shadow offset position |
| Sigma | Blur strength (X, Y) |
| Color | Shadow color |
| Shadow Only | Show shadow only. Default: Off |

### Flat Shadow
Generates a directional flat shadow from the object's contour.

| Property | Description |
| --- | --- |
| Angle | Shadow angle |
| Length | Shadow length |
| Brush | Shadow brush. Default: Gray |
| Shadow Only | Show shadow only. Default: Off |

| Property | Description |
| --- | --- |
| Color | Color to key |
| Brightness Range | Tolerance range |
| Boundary Correction | Boundary smoothness. Default: 2 |

| Property | Description |
| --- | --- |
| Radius X | X radius |
| Radius Y | Y radius |

### Dilate
Morphological dilation that expands bright areas and shrinks dark areas.

| Property | Description |
| --- | --- |

## Transform & Animation

### Transform
Applies geometric transformations such as translation, rotation, scale, and skew.

| Property | Description |
| --- | --- |
| Transform | Transformation to apply |
| Transform Origin | Transform origin. Default: Center |

Generates natural shaking/jitter using Perlin noise. Time-based animation effect.

| --- | --- |
| Strength X | Horizontal shake strength. Default: 50 |
| Strength Y | Vertical shake strength. Default: 50 |
| Speed | Shake speed. Default: 100 |

Positions and optionally rotates the element along a path geometry.

| Property | Description |
| --- | --- |
| Geometry | Path shape |
| Progress | Progress (0-100%). Default: 0 |
| Follow Rotation | Rotate along path. Default: Off |

## About Effect Types

Effects are internally categorized into three types:

1. **Image Filters** - Such as Blur and Drop Shadow. Can be composed with other image filters.
2. **Color Filters** - Such as Hue Rotate and High Contrast. Can be converted to image filters.
3. **Custom Effects** - Such as CvBlur, using external libraries. Requires a rasterized image.

Beutl automatically optimizes these effects for efficient processing.
For details, see [Effect Application Process](../advanced/3.filter-effect.md).
