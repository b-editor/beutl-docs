# Script Effects

Script Effects allow you to create custom visual effects using shader languages. Beutl supports two types of script effects: SKSL Script Effect and GLSL Script Effect.

## SKSL Script Effect

SKSL Script Effect uses Skia's shader language (SKSL), which is a simplified shader language that works cross-platform. This is the recommended option for most use cases due to its portability.

### Available Variables

When writing SKSL shaders, the following variables are available:

- `src` - The input image (texture)
- `progress` - Animation progress from 0.0 to 1.0
- `duration` - Total duration in seconds
- `time` - Current time in seconds
- `width` - Render width in pixels
- `height` - Render height in pixels
- `iResolution` - Resolution vector (compatible with Shadertoy)
- `iTime` - Time in seconds (compatible with Shadertoy)

### Default SKSL Template

```glsl
uniform shader src;
uniform float progress;
uniform float duration;
uniform float time;
uniform float width;
uniform float height;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / float2(width, height);
    half4 color = src.eval(fragCoord);

    // Add your effect here

    return color;
}
```

## GLSL Script Effect

GLSL Script Effect uses standard GLSL with the Vulkan backend. This option provides more advanced features but only works on platforms with 3D rendering support.

### Available Variables

The same variables available in SKSL are also available in GLSL as push constants:

- `src` - The input image (texture)
- `progress` - Animation progress from 0.0 to 1.0
- `duration` - Total duration in seconds
- `time` - Current time in seconds
- `width` - Render width in pixels
- `height` - Render height in pixels
- `iResolution` - Resolution vector
- `iTime` - Time in seconds

### Default GLSL Template

```glsl
#version 450

layout(set = 0, binding = 0) uniform sampler2D src;

layout(push_constant) uniform PushConstants {
    float progress;
    float duration;
    float time;
    float width;
    float height;
};

layout(location = 0) in vec2 fragCoord;
layout(location = 0) out vec4 outColor;

void main() {
    vec2 uv = fragCoord / vec2(width, height);
    vec4 color = texture(src, uv);

    // Add your effect here

    outColor = color;
}
```

## Platform Compatibility

- **SKSL Script Effect**: Works on all platforms (Windows, macOS, Linux)
- **GLSL Script Effect**: Only works on platforms with Vulkan support and 3D rendering enabled

## Tips

- Start with SKSL for better cross-platform compatibility
- Use GLSL when you need advanced features specific to Vulkan
- Test your shaders with different input sizes and durations
- Use the `progress` variable to create time-based animations
