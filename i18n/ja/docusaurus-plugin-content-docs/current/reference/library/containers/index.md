# コンテナ

1 つ以上の子要素を包んで、グループ化・装飾・タイミング制御を行うコンテナです。

- [**デコレーター**](./decorator.md) — 別の描画オブジェクトを包み、追加のトランスフォームやエフェクトを適用します。
- [**グループ**](./group.md) — 複数の描画オブジェクトをグループ化し、1 つのレイヤーとして扱います。
- [**サウンドグループ**](./sound-group.md) — 複数のサウンドソースをグループ化し、1 つの出力にミックスします。
- [**タイムコントローラー（動画）**](./time-controller-video.md) — 子の描画オブジェクトの再生タイミング（オフセットと速度）を制御します。
