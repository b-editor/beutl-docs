# コーナーピン

レイヤーの四隅を任意の 4 点に動かし、その間の絵を遠近感を付けて引き伸ばします。平らなカードを斜めから見たような形になります。映像の中の画面や看板に絵をはめ込んだり、タイトルを奥へ傾けたりするのに使います。四隅はプレビューでドラッグするか、プロパティパネルで位置を入力して指定します。四隅が既定値のときは、レイヤーは変わりません。

四隅は凸の四角形を作る必要があります。ある隅がほかの 2 つの隅を結ぶ線を越えて、形がへこんだりねじれたりしたとき、または 3 つの隅が一直線に並んだときは、その隅を戻すまでレイヤーが表示されなくなります。左の隅を右側へ、右の隅を左側へ動かすと、レイヤーが左右反転します。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → コーナーピン

## プレビューで四隅を編集する

1. プロパティタブで、エフェクトの目のアイコンの左にある十字のボタン **フレームで編集** をクリックします。[エフェクトのハンドルをプレビューで編集する](../../tool-tabs/element-property.md#effect-handles)を参照してください。
2. プレビューに、四隅の青い点と、それらを結ぶ線が表示されます。その間、オブジェクト自体のトランスフォームハンドルは隠れます。コーナーピンより後にエフェクトがあるときは、編集中のプレビューではそれらを非表示にするので、四隅はコーナーピンが作る絵の上に置かれます。そのことはプレビュー下部の案内に表示されます。再生するか要素を選択すると、後のエフェクトがまた表示されます。
3. 隅をドラッグします。隅はレイヤーの範囲の外にも動かせ、絵はそこまで引き伸ばされます。ドラッグ 1 回が 1 回の取り消し単位になり、`Esc` でキャンセルできます。ドラッグでレイヤーが表示されなくなっても点は残るので、隅をドラッグして戻せます。

隅にキーフレームがあるときは、ドラッグすると現在のフレームのキーフレームが変わり、そこにキーフレームがなければスプラインイージングで追加されます。[成分を分離](../../../get-started/keyframe.md#separate-components)で X と Y を別々にアニメーションさせているときは、ドラッグで両方が変わりますが、式が設定された成分は変わりません。隅に式が設定されている間は、ドラッグしても何も起こりません。

## プロパティ

### 左上 (TopLeft)

レイヤーの左上の隅を移す位置を、レイヤーの範囲を基準に指定します。パーセントの値はレイヤーの大きさに対する割合で、レイヤーの大きさが変わるとそれに合わせて動きます。ピクセルの値は、レイヤーの範囲の左上からの距離です。プレビューでドラッグしても、隅の単位は変わりません。

- **型:** `RelativePoint`
- **既定値:** `(0%, 0%)`
- **アニメーション:** 可

### 右上 (TopRight)

レイヤーの右上の隅を移す位置です。指定のしかたは `左上` と同じです。

- **型:** `RelativePoint`
- **既定値:** `(100%, 0%)`
- **アニメーション:** 可

### 右下 (BottomRight)

レイヤーの右下の隅を移す位置です。指定のしかたは `左上` と同じです。

- **型:** `RelativePoint`
- **既定値:** `(100%, 100%)`
- **アニメーション:** 可

### 左下 (BottomLeft)

レイヤーの左下の隅を移す位置です。指定のしかたは `左上` と同じです。

- **型:** `RelativePoint`
- **既定値:** `(0%, 100%)`
- **アニメーション:** 可

## 使い方

映像の中の画面に絵をはめ込むには、絵の要素を映像より上のレイヤーに置き、絵にコーナーピンを追加して **フレームで編集** をクリックし、各隅を画面の対応する隅までドラッグします。画面が動くときは、隅にキーフレームを追加してから別のフレームに移動し、もう一度隅をドラッグします。タイトルを奥へ傾けるには、`左上` と `右上` を互いに近づけます。
