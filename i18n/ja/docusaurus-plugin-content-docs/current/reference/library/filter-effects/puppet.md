# パペット

レイヤーに置いたピンに合わせて、レイヤーを曲げます。プレビューで絵をクリックしてピンを置き、ピンをドラッグすると、絵がそれに付いてきます。絵はピンの間でできるだけ硬さを保ったまま曲がるので、ピンが許す範囲で各部分の形が保たれます。ピンの位置はピンごとにアニメーションできるので、ピンにキーフレームを打つと、レイヤーを操り人形のように動かせます。

曲がるのは絵の見えている部分だけで、透明な穴は穴のまま残ります。テキストの文字のように互いに接していない部分は、別々に曲がります。ピンが 1 つの部分は回転せずにそのピンと一緒に動き、ピンが 2 つ以上の部分はピンの間で曲がり、ピンのない部分はその場に残ります。曲げた絵の縁は 1 ピクセルほどの幅でなめらかに描かれるので、ギザギザになりません。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → パペット

## プレビューでピンを編集する

### ピンを置く

1. プロパティタブで、**ピン** のリストの見出しにある `+` ボタン（**ピンを追加**）をクリックします。エフェクトが選択され、再生が止まり、プレビューは **移動** ツールに切り替わります。プレビューの下部に **ピンの配置を準備中…**、続いて **画像上をクリックして配置。Escで終了** と表示されます。
2. ピンで留めたい位置で絵をクリックします。クリックするたびにピンが 1 つ追加されて選択され、1 回の取り消し単位になります。透明な場所やフレームの外をクリックしたときは、次のクリックを待ちます。この間もプレビューの拡大と移動はできます。[プレビュー上の操作部](../../tool-tabs/preview-settings.md#controls-on-the-preview)を参照してください。
3. 配置を終えるには、`Esc` を押すか、その間 ✓（**配置を終了**）に変わる同じボタンをクリックするか、プレビューを右クリックします。再生位置を動かしたとき、再生を始めたとき、ほかのプレビューツールを選んだとき、ほかのものを選択したときも配置は終わります。既存のピンを押すと、配置が終わり、そのピンのドラッグが始まります。

すでに曲がっている絵にもピンを置けます。新しいピンは、クリックした絵の点を今描かれている位置で留めます。配置中に元に戻すと最後のピンが取り消され、そのまま配置を続けられます。再生位置でレイヤーに何も表示されていないときは、**このフレームにはピンを置ける画像がありません。** という通知が表示されます。

### ピンを動かす・削除する

エフェクトの目のアイコンの左にある十字のボタン **フレームで編集** をクリックするか、**ピン** のリストでピンの行をクリックすると、プレビューにピンが表示されます。ピンが表示されるのは **移動** ツールが有効で再生が停止している間で、行をクリックしたときは **移動** ツールに切り替わります。[エフェクトのハンドルをプレビューで編集する](../../tool-tabs/element-property.md#effect-handles)を参照してください。

- 各ピンは、**ピン** のリストでの行の番号が書かれた円で表示されます。選択中のピンは白地に青い輪で、ほかのピンの上に表示されます。プレビューを拡大・縮小しても、ピンの画面上の大きさは変わりません。
- その間、オブジェクト自体のトランスフォームハンドルと基準点は隠れます。エフェクトにピンがまだないときも同じです。
- パペットの後ろにほかのエフェクトがあるときは、その間それらがプレビューで非表示になるので、ピンはパペットが作る絵の上に重なります。プレビューの下部には **パペットのピンを編集中。プレビューでは後続のエフェクトを一時的に非表示にしています。** と表示されます。再生中、**移動** 以外のツールを選んでいるとき、ほかのものを選択したときは、後続のエフェクトも表示されます。

ピンをドラッグすると移動できます。押したピンは選択もされます。ピンはレイヤーの範囲の外にも動かせ、絵はそこまで付いてきます。修飾キーはドラッグに影響しません。ドラッグ 1 回が 1 回の取り消し単位になります。ドラッグ中に `Esc` を押すか元に戻す操作をするとピンは元の位置に戻り、再生を始めるとその時点の位置でドラッグが終わります。

ピンの **位置** にキーフレームがあるときは、ドラッグすると現在のフレームのキーフレームが変わり、そこにキーフレームがなければスプラインイージングで追加されます。[成分を分離](../../../get-started/keyframe.md#separate-components)で X と Y を別々にアニメーションさせているときは、ドラッグで両方が変わりますが、式が設定された成分は変わりません。**位置** に式が設定されている間は、ピンをドラッグしても何も起こりません。

ピンを削除するには、ピンを選択して、**ピン** のリストの見出しにある `−` ボタン（**選択したピンを削除**）をクリックします。続いて、その次のピン、または最後のピンが選択されます。

### プロパティパネルのピンの行

**ピン** のリストは常に開いています。各ピンの行には、番号と **X**、**Y** のボックスがあります。番号にポインターを乗せると、座標の意味が表示されます。行やその中のボックスをクリックすると、そのピンが選択されてプレビューにピンが表示され、選択中のピンの行は強調表示されます。

- **X** と **Y** に値を入力すると、ピンを正確な位置に置けます。
- ピンの番号を上下にドラッグすると、ピンの順序を変えられます。プレビューの番号も合わせて変わります。
- 行の ⋮ ボタンで、ほかのプロパティと同じようにピンの位置にキーフレームや式を設定できます。[キーフレーム](../../../get-started/keyframe.md)を参照してください。ピンにキーフレームがあるときは、行の矢印で前後のキーフレームへ移動できます。**成分を分離** したあとは、このボタンで分離した **X** と **Y** の行がポップアップで開きます。
- 行のメニューの **リセット** は、ピンを曲げる前の絵でピンの点がある位置に戻すので、ピンはその点を動かさなくなります。位置にキーフレームがあるときは、再生位置のキーフレームだけが変わります。分離した **X** や **Y** の行では、その座標だけがリセットされます。

## プロパティ

### ピン (Pins)

ピンのリストで、番号の順に並びます。各ピンは置いたときの絵の点を留め、その **位置** が点の行き先を表します。どのピンも点を動かしていない間は、レイヤーは変わりません。

- **型:** `IListProperty<PuppetPin>`
- **既定値:** 空のリスト
- **アニメーション:** 不可（各ピンの **位置** は可）

#### 位置 (Position)

ピンが留める絵の点の行き先を、パペットが受け取る絵に対する相対座標で表します。`(0, 0)` が左上、`(1, 1)` が右下です。`0` 〜 `1` の外の値にすると、点は絵の元の範囲の外へ出ます。

- **型:** `Point`
- **既定値:** ピンを置くときにクリックした位置
- **アニメーション:** 可

## 使い方

1 枚の絵として描いたキャラクターの肩、ひじ、手、足など、関節にピンを置きます。手のピンをドラッグしてキーフレームを打つと、腕を振らせられます。足のように動かさないピンは、その部分を止めておきます。テキストでは文字ごとにピンを置きます。ピンが 1 つの文字は動くだけなので、傾けたり曲げたりするにはピンを 2 つ置きます。
