# フィルターエフェクト

描画結果に対して後段で適用されるフィルターエフェクトです。連結やアニメーションが可能で、Script サブグループのカスタムシェーダーと組み合わせることもできます。

- [**ぼかし**](./blur.md) — レイヤーにガウスぼかしを適用します。
- [**ドロップシャドウ**](./drop-shadow.md) — レイヤーの背後に影を落とします。
- [**内側シャドウ**](./inner-shadow.md) — レイヤーの内側にシャドウを追加します。
- [**フラットシャドウ**](./flat-shadow.md) — レイヤーから平面（ロング）シャドウを投影します。
- [**ストローク**](./stroke.md) — レイヤーの周囲にアウトライン（ストローク）を描画します。
- [**クリッピング**](./clipping.md) — レイヤーを矩形領域でクリップします。
- [**膨張**](./dilate.md) — 不透明な領域を膨張させます（モルフォロジーの膨張処理）。
- [**収縮**](./erode.md) — 不透明な領域を収縮させます（モルフォロジーの収縮処理）。
- [**ハイコントラスト**](./high-contrast.md) — コントラストを強調します。グレースケールや反転モードも併用できます。
- [**色相調整**](./hue-rotate.md) — レイヤーの色相を回転させます。
- [**明るさ調整**](./lighting.md) — 乗算と加算で明るさを調整します。
- [**LumaColor**](./lumacolor.md) — レイヤーの輝度をアルファにマッピングしてルミナンスマットを作成します。
- [**彩度調整**](./saturate.md) — 色の彩度を調整します。
- [**二階調化**](./threshold.md) — 輝度のしきい値で 2 階調化します。
- [**輝度**](./brightness.md) — 全体の輝度を調整します。
- [**ガンマ**](./gamma.md) — レイヤーにガンマ補正を適用します。
- [**カラーグレーディング**](./color-grading.md) — カーブ・リフト/ガンマ/ゲイン・色温度・ティントを使ったプロ向けのカラーグレーディングを行います。
- [**カーブ**](./curves.md) — マスター・RGB・HSV のカーブで階調を調整します。
- [**反転**](./invert.md) — レイヤーの色を反転します。
- [**LUT (Cubeファイル)**](./lut-cube-file.md) — `.cube` ファイルから読み込んだ 3D LUT を適用します。
- [**ブレンド**](./blend.md) — 指定したブレンドモードでレイヤーを合成します。
- [**ネガポジ**](./negaposi.md) — 色チャンネルごとに反転処理を行います。
- [**クロマキー**](./chroma-key.md) — 色相範囲を抜いてグリーン／ブルーバックを除去します。
- [**カラーキー**](./color-key.md) — RGB 距離をもとに特定の色範囲を除去します。
- [**均等に分割**](./split-equally.md) — レイヤーを等間隔のタイルに分割します。
- [**パーツごとに分割**](./split-by-parts.md) — 連結成分ごとに個別のサブターゲットへ分割します。
- [**トランスフォーム**](./transform.md) — レイヤー本体の Transform とは独立に、フィルターとして 2D トランスフォームを適用します。
- [**モザイク**](./mosaic.md) — レイヤーをモザイク状のブロックにピクセル化します。
- [**色ずれ**](./color-shift.md) — RGB とアルファの各チャンネルを個別にずらして色収差風の演出を行います。
- [**振動**](./shake.md) — レイヤーにランダムな振動（シェイク）を加えます。
- [**ディスプレイスメントマップ**](./displacement-map.md) — 別のレイヤーをディスプレイスメントマップとして用いてレイヤーを歪ませます。
- [**パス追従**](./path-follow.md) — レイヤーをパスジオメトリーに沿わせるように変形させます。
- [**レイヤー**](./layer.md) — 現在のレイヤーではなく、参照した別のレイヤーにフィルターエフェクトのチェーンを適用します。
- [**遅延アニメーション**](./delay-animation.md) — 後続のエフェクトの適用タイミングを遅らせます。
- [**ピクセルソート**](./pixel-sort.md) — 指定した方向に沿って、明度や色相でピクセルをソートします。
- [**ノードグラフ（エフェクト）**](./node-graph-effect.md) — ノードグラフをカスタムフィルターエフェクトとして利用します。
