# 極座標

レイヤーを円に巻き付けて横の帯を輪に曲げるか、円の輪を横の帯に展開します。円はレイヤーの縦横比にかかわらず真円になり、`元のサイズにクリップ` がオフなら、出力の範囲は結果に合わせて広がったり縮んだりします。`極座標から直交座標へ` は逆向きの変換なので、`直交座標から極座標へ` で作った円を帯に戻せます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → 極座標

## プロパティ

### 方向 (Direction)

レイヤーをどちらの向きに変換するかです。

- **型:** `PolarCoordinatesDirection`
- **既定値:** `PolarCoordinatesDirection.RectangularToPolar`（直交座標から極座標へ）
- **アニメーション:** 不可

選べる値は次のとおりです。

- `直交座標から極座標へ`: `中心` を中心とする円にレイヤーを巻き付けます。左端が 12 時の位置から始まって時計回りに巻き付き、右端が同じ位置で左端とつながります。最上行が円の縁に、最下行が中心に移るので、1 行のテキストは文字の上側を外に向けて円の上に並びます。
- `極座標から直交座標へ`: その逆です。`中心` の周りの円を読み取って帯に展開します。12 時の位置から時計回りに測った角度が左から右へ並び、円の縁が上端に、中心が下端に来るので、輪は横の帯に、放射状の線は縦の線になります。

### 量 (Amount)

各ピクセルを変換先の位置へどれだけ動かすかをパーセントで指定します。`0` ではレイヤーを変更せず、`100` で変換を完全に適用します。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 中心幅 (InnerRadius)

円の中央に穴を開けて、レイヤーを輪にします。レイヤーの中心側に、このピクセル数の高さの空白の帯を足したものとして巻き付けるので、値を大きくするほど穴が広がり、その分だけ円も大きくなります。`極座標から直交座標へ` では、展開から除く中央部分の半径をピクセル単位で指定し、`スケール` を掛けた値が使われます。その外側の輪だけが展開されます。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[0, ∞)`

### スケール (Scale)

円の大きさをパーセントで指定します。`100` では、円の半径はレイヤーの幅と高さと `中心幅` の合計を π で割った値になります。そのため、正方形のレイヤーからは幅がレイヤーより 4 分の 1 ほど広い円が、長い 1 行のテキストからは直径がテキストの長さの 3 分の 2 ほどの円ができます。`中心幅` による穴も同じ割合で大きさが変わります。`極座標から直交座標へ` では、`100` のときに読み取る円の半径がレイヤーの短い辺の半分になるので、`中心` が中央にあれば円はレイヤーに収まります。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, ∞)`

### 角度 (Angle)

巻き付けを始める位置を、12 時の位置から時計回りに測った角度（度）で指定します。レイヤーの左端がここに来るので、アニメーションさせると輪が回転します。`極座標から直交座標へ` では、帯の左端がここから円を読み取ります。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 渦巻 (Swirl)

輪をねじって渦巻きにする角度（度）です。縁は動かず、内側の輪ほど大きく回り、内側の縁（`中心幅` が `0` なら中心）でこの角度に達します。正の値では内側が反時計回りに回ります。`極座標から直交座標へ` では同じねじれで読み取るので、同じ `渦巻` で作った渦巻きがまっすぐに戻ります。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 角度範囲 (SweepAngle)

円のうちレイヤーを巻き付ける範囲の角度（度）です。`360` 未満では、レイヤーは `角度` から時計回りに伸びる円弧に曲がり、円の残りの部分を何で埋めるかは `端の処理` で決まります。`極座標から直交座標へ` では、その円弧だけを展開し、帯もそれに合わせて短くなります。

- **型:** `float`
- **既定値:** `360`
- **アニメーション:** 可
- **範囲:** `[0, 360]`

### 中心 (Center)

レイヤーの範囲を基準にした円の中心です。`直交座標から極座標へ` はこの点の周りに円を描き、`極座標から直交座標へ` はこの点の周りの円を読み取ります。

- **型:** `RelativePoint`
- **既定値:** `(50%, 50%)`
- **アニメーション:** 可

### 内外反転 (InvertRadius)

`true` のときは、レイヤーの最上行が中心（または輪の内側の縁）に、最下行が縁に移ります。`極座標から直交座標へ` では、中心が帯の上端に、縁が下端に来ます。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

### 角度反転 (ReverseAngle)

`true` のときは、レイヤーを時計回りではなく反時計回りに巻き付けます。`極座標から直交座標へ` では、帯が円を反時計回りに読み取ります。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

### 繰り返し (Repeat)

円（または `角度範囲` の円弧）に沿ってレイヤーを何回並べるかです。`2` ではレイヤーが 2 つ続けて並び、小数では最後の 1 つが途中で切れ、`1` 未満ではレイヤーの一部が円全体に引き伸ばされます。`極座標から直交座標へ` では、展開した円がこの回数だけ帯に横に並びます。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.01, ∞)`

### ミラー (Mirror)

`true` のときは、`繰り返し` で並んだレイヤーを 1 つおきに反転させるので、隣どうしが継ぎ目なくつながります。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

### 端の処理 (EdgeMode)

変換がレイヤーの外側を読み取る場所を何で埋めるかです。`直交座標から極座標へ` では、円の外側、`中心幅` による穴、`角度範囲` から外れた円の部分がこれに当たります。`極座標から直交座標へ` では、円のうちレイヤーの端からはみ出した部分がこれに当たります。

- **型:** `PolarCoordinatesEdgeMode`
- **既定値:** `PolarCoordinatesEdgeMode.Transparent`（透明）
- **アニメーション:** 不可

選べる値は次のとおりです。

- `透明`: 透明のままにします。
- `クランプ`: レイヤーの最も近い端のピクセルを引き伸ばして埋めます。
- `繰り返し`: レイヤーを繰り返して埋めます。
- `ミラー`: レイヤーを 1 回おきに反転させながら繰り返して埋めます。

`透明` 以外では、`直交座標から極座標へ` の出力の範囲は、円に加えてレイヤー自身の範囲も含みます。

### 元のサイズにクリップ (ClipToBounds)

`true` のときは、出力の範囲をレイヤーの範囲のままにし、そこからはみ出す部分を切り取ります。`false` のときは、出力の範囲を結果に合わせます。`直交座標から極座標へ` では円を囲む正方形になります。`極座標から直交座標へ` では、レイヤーの中央に置かれた帯になり、その長さは輪の幅の中ほどを通る円（`角度範囲` が `360` 未満ならその円弧）の長さ、高さは輪の幅と同じです。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

## 使い方

1 行のテキストやグラデーションのような横長の帯に `直交座標から極座標へ` を適用すると、輪の形に巻き付けられます。`中心幅` を上げると中央に穴が開き、`角度範囲` を下げると円弧に曲がり、`角度` をアニメーションさせると輪が回転します。`繰り返し` を上げて `ミラー` をオンにすると、万華鏡のような模様になります。`量` を `0` から `100` までアニメーションさせると、レイヤーが少しずつ輪に曲がっていきます。
