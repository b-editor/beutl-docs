# カラーグレーディング

プロ向けのカラーグレーディング機能です。ホワイトバランス・露出・コントラスト（ピボット付き）・彩度 / 自然な彩度・色相に加えて、シャドウ / ミッドトーン / ハイライト、リフト / ガンマ / ゲイン の各ホイールが使えます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → カラーグレーディング

## プロパティ

### 色温度 (Temperature)

ホワイトバランスの色温度（-100 が寒色、+100 が暖色）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### 色かぶり補正 (Tint)

ホワイトバランスのティント（-100 が緑、+100 がマゼンタ）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### 露出 (Exposure)

露出補正（ストップ単位）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-5, 5]`

### コントラスト (Contrast)

コントラストの調整量。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### コントラストのピボット (ContrastPivot)

コントラスト調整のピボットになる輝度値（0〜1）。

- **型:** `float`
- **既定値:** `0.5`
- **アニメーション:** 可
- **範囲:** `[0, 1]`

### 彩度 (Saturation)

線形な彩度調整。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### バイブランス (Vibrance)

すでに彩度の高い色や肌色を保護する自然な彩度調整。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### 色相 (Hue)

全体の色相シフト（度）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-180, 180]`

### ローレンジ (LowRange)

「シャドウ」階調領域の上限。

- **型:** `float`
- **既定値:** `40`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### ハイレンジ (HighRange)

「ハイライト」階調領域の下限。

- **型:** `float`
- **既定値:** `60`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### シャドウ (Shadows)

シャドウ領域へのカラーオフセット。

- **型:** `GradingColor`
- **既定値:** `(0, 0, 0)`
- **アニメーション:** 可

### ミッドトーン (Midtones)

ミッドトーン領域へのカラーオフセット。

- **型:** `GradingColor`
- **既定値:** `(0, 0, 0)`
- **アニメーション:** 可

### ハイライト (Highlights)

ハイライト領域へのカラーオフセット。

- **型:** `GradingColor`
- **既定値:** `(0, 0, 0)`
- **アニメーション:** 可

### リフト (Lift)

古典的なカラーグレーディングの Lift（シャドウ色）。

- **型:** `GradingColor`
- **既定値:** `(0, 0, 0)`
- **アニメーション:** 可

### ガンマ (Gamma)

古典的な Gamma（ミッドトーン色）。

- **型:** `GradingColor`
- **既定値:** `(1, 1, 1)`
- **アニメーション:** 可

### ゲイン (Gain)

古典的な Gain（ハイライト色）。

- **型:** `GradingColor`
- **既定値:** `(1, 1, 1)`
- **アニメーション:** 可

### オフセット (Offset)

すべての階調に加算する一定のオフセット。

- **型:** `GradingColor`
- **既定値:** `(0, 0, 0)`
- **アニメーション:** 可
