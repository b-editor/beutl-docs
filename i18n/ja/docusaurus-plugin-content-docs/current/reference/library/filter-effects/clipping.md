# クリッピング

`左` / `上` / `右` / `下` の内側オフセットで定義される矩形にレイヤーをクリップします。マイナスの値を指定すると領域を拡張できます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → クリッピング

## プロパティ

### 左 (Left)

左端からクリップする距離。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 上 (Top)

上端からクリップする距離。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 右 (Right)

右端からクリップする距離。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 下 (Bottom)

下端からクリップする距離。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### 自動センタリング (AutoCenter)

`true` のとき、内側オフセットが変わってもクリップ後の領域を中央に保ちます。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

### 透明部分をクリップ (AutoClip)

`true` のとき、元レイヤーの境界に自動的にクリップします。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

## 使い方

不要な端をトリミングするのに使います。
