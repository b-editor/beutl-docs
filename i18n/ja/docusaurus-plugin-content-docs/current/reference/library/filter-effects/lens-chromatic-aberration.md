# 色収差 (レンズ)

レイヤーに、実際のレンズのような色のにじみを加えます。緑のチャンネルはそのままに、赤と青のチャンネルを中心点を基準に逆向きに拡大・縮小するので、中心では絵がにじまず、端に近づくほど色が離れていきます。各チャンネルを決まった量だけずらす[色ずれ](./color-shift.md)と違い、ずれは中心からの距離に応じて大きくなります。このエフェクトには GPU テクスチャと GLSL の実行が必要です。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → 色収差 (レンズ)

## プロパティ

### 量 (Amount)

チャンネルをどれだけ離すかをパーセントで指定します。赤は外側へ、青は内側へ、`中心` からの距離の `量` パーセント分だけ動きます。既定の `1` では、中心から 1000 ピクセルの位置でそれぞれ 10 ピクセル動きます。負の値では色が入れ替わり、青が外側へ、赤が内側へ動きます。`0` ではレイヤーを変更しません。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[-10, 10]`

### 中心 (Center)

チャンネルを拡大・縮小する基準点を、レイヤーの範囲を基準に指定します。この点では色がにじみません。レイヤーの外側にも配置できます。

- **型:** `RelativePoint`
- **既定値:** `(50%, 50%)`
- **アニメーション:** 可

### 端のピクセルを繰り返す (RepeatEdgePixels)

`true` のときは、チャンネルがレイヤーの端より外側を読む場所で、いちばん外側のピクセルを繰り返します。端の色が保たれ、結果はレイヤーの範囲内に収まります。範囲いっぱいに絵がある映像、画像、[調整レイヤー](../../tool-tabs/timeline.md#何もない場所の右クリックメニュー)ではオンのままにします。`false` のときは色のにじみがレイヤーの端の外側まで広がり、透明な背景の上のオブジェクトやタイトルに向きます。範囲いっぱいに絵があるレイヤーでは、このとき端に色の付いた帯ができます。

- **型:** `bool`
- **既定値:** `true`
- **アニメーション:** 可

## 使い方

映像か、その上の調整レイヤーにこのエフェクトを追加し、`量` を `1`〜`3` 程度にすると、控えめなレンズの風合いになります。`中心` を被写体に合わせると、被写体に色のにじみが出ません。透明な背景の上の切り抜いたオブジェクトやタイトルでは、`端のピクセルを繰り返す` をオフにすると、色のにじみが端の外側まで届きます。`量` を `10` まで上げて戻すキーフレームを打つと、拍に合わせた一瞬の色割れになります。
