# フィルムグレイン

レイヤーにフィルムのような粒子（グレイン）を加えます。グレインは中間調で最も強く、黒と白に近づくほど弱くなり、黒と白そのものの色は変わりません。透明度は変わらず、透明なピクセルにはグレインが付きません。グレインの大きさはレイヤー自体のピクセルで決まるので、解像度を下げたプレビューでも書き出しと同じ粒子感で表示されます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → フィルムグレイン

## プロパティ

### 量 (Amount)

グレインの強さです。`0` ではグレインを加えません。

- **型:** `float`
- **既定値:** `25`
- **アニメーション:** 可
- **範囲:** `[0, ∞)`

### サイズ (Size)

グレインの粒の大きさを、レイヤーのピクセル単位で指定します。値を大きくすると粒が粗くなります。

- **型:** `float`
- **既定値:** `1.5`
- **アニメーション:** 可
- **範囲:** `[0.1, ∞)`

### 柔らかさ (Softness)

隣り合う粒どうしをどれだけなめらかにつなぐかです。`0` では粒が角張った四角になります。

- **型:** `float`
- **既定値:** `50`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### カラー (Color)

`0` ではすべてのチャンネルで同じグレインを使うので、グレインに色が付きません。`100` ではチャンネルごとに異なるグレインを使います。その間の値では両方を混ぜ、グレインの強さは両端と変わりません。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### シード (Seed)

グレインの模様を別のものに変えます。

- **型:** `int`
- **既定値:** `0`
- **アニメーション:** 可

### アニメーション (Animate)

`true` のときは、要素の開始から数えたフレームごとに模様が変わります。`false` のときは、模様が止まったままになります。

- **型:** `bool`
- **既定値:** `true`
- **アニメーション:** 可

## 使い方

映像か、その上の[調整レイヤー](../../tool-tabs/timeline.md#何もない場所の右クリックメニュー)にこのエフェクトを追加し、グレインが見えるまで `量` を上げます。粒を粗くするには `サイズ` を、粒に色のばらつきを付けるには `カラー` を上げます。写真のように止まったグレインにするには `アニメーション` をオフにします。
