# エコー

過去や未来の時刻のレイヤーのコピーを現在のレイヤーと一緒に描画し、コピーごとに 1 つ前より薄くして、軌跡や残像、ゴーストを作ります。各コピーには、その時刻のレイヤーの位置、映像のフレーム、エコーより前のエフェクトが反映されます。エコーより後のエフェクトとレイヤーのブレンドモードは、重ねた結果に 1 回だけ適用されます。要素の範囲外の時刻のコピーは空になるので、`間隔` が負の値のときは、要素の開始後に軌跡が少しずつ伸びていきます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → エコー

## プロパティ

### 間隔 (秒) (Interval)

コピー間の時間差を秒で指定します。負の値では過去の時刻のコピーになり、動くレイヤーの後ろに軌跡が残ります。正の値では未来の時刻のコピーになり、レイヤーの先を行きます。`0` では現在の時刻を繰り返します。

- **型:** `float`
- **既定値:** `-0.1`
- **アニメーション:** 可
- **範囲:** `[-60, 60]`

### 個数 (Count)

現在のコピーを含むコピーの数です。増やすと描画時間とメモリ使用量が増えます。

- **型:** `int`
- **既定値:** `4`
- **アニメーション:** 不可
- **範囲:** `[1, 64]`

### 初期強度 (StartingIntensity)

現在のコピーの不透明度をパーセントで指定します。ほかのコピーはここから `減衰` に従って薄くなります。`0` ではすべてのコピーが透明になり、レイヤーは見えなくなります。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 減衰 (Decay)

各コピーが 1 つ前のコピーから引き継ぐ不透明度の割合をパーセントで指定します。既定値では、4 つのコピーの不透明度は 100%、70%、49%、34.3% になります。`0` では現在のコピーだけを描画し、`100` ではすべてのコピーが同じ不透明度になります。

- **型:** `float`
- **既定値:** `70`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### ブレンドモード (BlendMode)

重なったコピーをどう合成するかです。

- **型:** `EchoBlendMode`
- **既定値:** `EchoBlendMode.Add`（加算）
- **アニメーション:** 不可

選べる値は次のとおりです。

- `最新を手前に`: コピーを通常どおり重ね、最も新しい時刻のコピーを手前に描画します。`間隔` が負の値のときは現在のコピーが手前になり、不透明な部分ではエコーを隠すので、透明な背景の上のオブジェクトに向きます。
- `加算`: 重なったコピーの色を足し合わせるので、コピーが重なる部分で軌跡が光ります。止まっている部分も自分自身と足し合わされ、コピーの不透明度の合計の分だけ明るくなります。既定値では約 2.5 倍です。

## 使い方

動くタイトル、図形、切り抜いたオブジェクトにエコーを追加すると、後ろに軌跡が残ります。なめらかな尾にするには `間隔` を `0` に近づけて `個数` を増やし、離れた残像にするには `間隔` を `0` から遠ざけます。映像では、既定の `加算` によって止まっている部分が明るくなります。明るさを保つには、コピーの不透明度の合計が約 100% になるまで `初期強度` を下げます。既定の `個数` と `減衰` では約 `40` です。各コピーに含めたいエフェクトはエコーより前に、ぼかしや発光のように軌跡全体にかけるエフェクトは後に配置します。
