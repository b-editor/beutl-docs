# ビネット

レイヤーの周辺に向かって暗く、または明るくします。形はレイヤーの範囲に合わせるので、範囲がフレーム全体になる[調整レイヤー](../../tool-tabs/timeline.md#何もない場所の右クリックメニュー)では、画面の周辺が暗くなります。透明度は変わりません。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → ビネット

## プロパティ

### 量 (Amount)

ビネットの強さです。正の値で周辺が暗くなり、負の値で周辺が白に向かって明るくなります。`0` ではレイヤーを変更しません。

- **型:** `float`
- **既定値:** `50`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### 中間点 (Midpoint)

ビネットが半分の強さになる位置を、中心から四隅までの距離に対するパーセントで指定します。値を小さくすると中心に近づきます。

- **型:** `float`
- **既定値:** `50`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 丸み (Roundness)

ビネットの形です。`0` ではレイヤーの縦横比に従うので、横長のレイヤーでは横長の楕円になります。正の値で丸くなり、`100` で円になります。負の値で四角に近づき、`-100` で角の丸い四角形に近づきます。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[-100, 100]`

### ぼかし (Feather)

変化しない中央部から最大の強さまでの移り変わりの幅です。`0` では境界がくっきりします。

- **型:** `float`
- **既定値:** `50`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 中心 (Center)

レイヤーの範囲を基準にしたビネットの中心です。

- **型:** `RelativePoint`
- **既定値:** `(50%, 50%)`
- **アニメーション:** 可

## 使い方

調整レイヤーにこのエフェクトを追加すると、その下にあるレイヤーすべてについて画面の四隅を暗くできます。より強くするには `中間点` を下げるか `量` を上げます。`中心` を被写体に寄せると、視線をそこへ誘導できます。
