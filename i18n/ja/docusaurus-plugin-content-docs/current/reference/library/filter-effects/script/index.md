# スクリプト

スクリプトベースのフィルターエフェクトでは、C#・SKSL・GLSL で独自のシェーダーを記述できます。

- [**C#スクリプト**](./csharp-script.md) — C# でカスタムフィルターエフェクトを定義します。
- [**SKSLスクリプト**](./sksl-script.md) — SkiaSharp Shading Language (SKSL) シェーダーでカスタムフィルターエフェクトを定義します。
- [**GLSLスクリプト**](./glsl-script.md) — GLSL シェーダーでカスタムフィルターエフェクトを定義します。
