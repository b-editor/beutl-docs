# コマ撮り風

レイヤーの動きを、コマ撮りや 2 コマ打ちのアニメーションのように段階的にします。要素の開始から数えて 1 秒あたり決まった回数だけレイヤーの絵を取り出し、次の絵を取り出すまで保持します。保持されるのはその時刻のレイヤー全体で、位置、映像のフレーム、このエフェクトより前のエフェクトが含まれます。このエフェクトより後のエフェクトは保持されず、なめらかに動き続けます。タイミングは要素の開始から数えるので、タイムライン上で要素を動かしても、保持される絵は変わりません。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → コマ撮り風

## プロパティ

### レート (fps) (FrameRate)

1 秒あたりの絵の数です。値を下げると、1 枚の絵を長く保持します。24 fps のプロジェクトで `12` にすると、1 枚の絵を 2 フレームずつ表示します。`0.5` のように `1` 未満のレートでは、1 枚の絵を 1 秒より長く保持します。

レートにキーフレームがあるときは、各絵をその時点のレートで 1 ステップ分ずつ保持するので、段階の速さがなめらかに変わり、前の絵に戻ることはありません。式によるレートは要素の開始からの時間全体に適用されるので、時間とともにレートを変えるときはキーフレームを使ってください。

- **型:** `float`
- **既定値:** `12`
- **アニメーション:** 可
- **範囲:** `[0.01, 240]`

## 使い方

アニメーションさせたタイトル、図形、映像にこのエフェクトを追加します。絵を同じフレーム数ずつ保持するには、24 fps なら `12` や `8`、30 fps なら `15` や `10` のように、プロジェクトのフレームレートを割り切れるレートにします。`4` 以下に下げると、よりカクカクした動きになります。`レート` を低い値からプロジェクトのフレームレートまでキーフレームで上げると、段階的な動きからなめらかな動きへ移ります。
