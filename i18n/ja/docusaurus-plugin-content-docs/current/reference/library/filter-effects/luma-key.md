# 輝度キー

明るさが `下限` と `上限` の間にある部分を残し、それ以外を透明にします。絵の暗い部分を抜いたり、ある範囲の明るさだけを残したりするときに使います。明るさは [二階調化](./threshold.md) と同じくリニア光の輝度で測り、フルスケールを超えるハイライトはフルスケールとして扱います。残った部分の色は変わりません。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → 輝度キー

## プロパティ

### 下限 (%) (Lower)

これより暗い部分を透明にします。

- **型:** `float`
- **既定値:** `25`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 上限 (%) (Upper)

これより明るい部分を透明にします。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 境界の滑らかさ (%) (Softness)

各限界の外側に付ける柔らかい境界の幅です。`下限` より下、または `上限` より上のこの範囲にある明るさは、急に切れずに徐々に透明になります。`0` では境界がくっきりします。

- **型:** `float`
- **既定値:** `5`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### 反転 (Invert)

`true` のとき、限界の外側を残し、2 つの限界の間を透明にします。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 可

## 使い方

暗い背景を抜くには、背景が消えるまで `下限` を上げ、境界が硬く見えるときは `境界の滑らかさ` を上げます。白い背景を抜くには、`下限` を `0` にして `上限` を下げます。2 つの限界の間を透明にするには `反転` をオンにします。
