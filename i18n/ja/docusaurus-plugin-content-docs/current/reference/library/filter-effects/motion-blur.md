# モーションブラー

露光区間内で描画オブジェクトを複数回描画して平均し、時間方向に動きをぼかします。各サンプルには、描画オブジェクト、そのトランスフォーム、不透明度、メディア、このエフェクトより前のエフェクトが含まれます。このエフェクトより後のエフェクトと描画オブジェクトのブレンドモードは、平均した結果に 1 回だけ適用されます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → モーションブラー

## プロパティ

### シャッター角 (°) (ShutterAngle)

1 フレームに対する露光時間です。`180` は半フレーム、`360` は 1 フレーム、`720` は 2 フレームです。最大は `3600`（10 フレーム）です。`0` では現在時刻だけを描画します。

- **型:** `float`
- **既定値:** `180`
- **アニメーション:** 可
- **範囲:** `[0, 3600]`

### 露光の基準位置 (ShutterPosition)

現在のフレームを露光区間の **中央**、**開始**、**終了** のどこに置くかを指定します。**終了** では残像が過去側に伸びます。

- **型:** `ShutterPosition`
- **既定値:** `ShutterPosition.Center`（中央）
- **アニメーション:** 不可

### サンプル数 (Samples)

露光区間内のサンプルの数。増やすと残像の隙間が減りますが、描画時間とメモリ使用量が増えます。`1` では現在時刻だけを描画します。

- **型:** `int`
- **既定値:** `8`
- **アニメーション:** 不可
- **範囲:** `[1, 64]`

### 元画像ミックス (%) (SourceMix)

現在時刻の元画像を混ぜる割合。`0` はモーションブラーのみ、`100` は元画像のみです。静止した素材の不透明度はどの値でも変わりません。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

## 使い方

トランスフォームをアニメーションさせた描画オブジェクトや、動きのある素材に追加します。描画オブジェクトと一緒に動かすエフェクトはこのエフェクトより前に、ぼかした結果に適用するエフェクトは後に配置します。サンプルの時刻は出力のフレームレートに従うので、`180` はどのレートでも半フレームです。
