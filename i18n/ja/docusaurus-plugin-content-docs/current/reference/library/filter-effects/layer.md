# レイヤー

テキストオブジェクトで `文字ごとに分割` を有効にした場合や `均等に分割` または `パーツごとに分割` を適用した場合など、複数の描画ターゲットがある状況で、複数のターゲットを一つのレイヤーとしてまとめてフィルターエフェクトの対象にできます。

## ライブラリでの場所

「ライブラリ」 → フィルターエフェクト → レイヤー

## プロパティ

_このオブジェクト固有のプロパティはありません。_
