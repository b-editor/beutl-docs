# 回転

`トランスフォームの起点` を中心に、指定した角度（度）でレイヤーを回転させます。

## ライブラリでの場所

「ライブラリ」 → トランスフォーム → 回転

## プロパティ

### 回転 (Rotation)

回転角度（度。正が時計回り）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
