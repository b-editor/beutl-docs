# トランスフォーム

描画オブジェクトの位置・回転・スケール・歪みを変更するトランスフォームです。

- [**移動**](./translate.md) — レイヤーを X / Y 軸方向に平行移動します。
- [**歪み**](./skew.md) — レイヤーを X / Y 軸方向に傾けます。
- [**スケール**](./scale.md) — レイヤーを X / Y / 全体スケールで拡大縮小します。
- [**回転**](./rotation.md) — レイヤーを 2D で回転します。
- [**回転3D**](./rotation-3d.md) — レイヤーを 3D 空間（X / Y / Z 軸）で回転します。
