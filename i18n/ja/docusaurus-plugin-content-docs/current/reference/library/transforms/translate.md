# 移動

レイヤーを X / Y 軸方向に平行移動します。両軸は独立にアニメーションできます。

## ライブラリでの場所

「ライブラリ」 → トランスフォーム → 移動

## プロパティ

### X

水平方向のオフセット（ピクセル）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可

### Y

垂直方向のオフセット（ピクセル）。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 可
