# ポータル

タイムラインに配置される非ビジュアルなオブジェクトで、自身のすぐ下に並ぶ要素（Z インデックスが連続して大きい要素）を取り込み、コンポジションのフローへ流し込みます。コンテナ系オブジェクト ── **グループ**、**デコレーター**、**サウンドグループ**, **3Dシーン** など ── は、このフローを消費して取り込まれた要素を自身の子要素として扱います。これにより、タイムライン上で隣り合う要素どうしを親子関係に組み立てられます。

## ライブラリでの場所

「ライブラリ」 → ポータル

## プロパティ

### 個数 (Count)

ポータルの直下にある要素のうち、フローへ取り込む個数（連続する Z インデックス分）。後続のコンテナ系オブジェクトは、ここで取り込まれた要素を子要素として受け取ります。

- **型:** `int`
- **既定値:** `0`
- **アニメーション:** 不可

### クリア (Clear)

`true` のとき、このポータルが要素を流し込む前に、それまでに溜まっていたフローの内容を破棄します。後続のコンテナへ上流のフロー出力を渡したくない場合に使用します。

- **型:** `bool`
- **既定値:** `false`
- **アニメーション:** 不可

## 共通プロパティ

このオブジェクトは `EngineObject` を継承しているため、基底クラスで宣言された[共通プロパティ](../common-properties.md)も利用できます。
