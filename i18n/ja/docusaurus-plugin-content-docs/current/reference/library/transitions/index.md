# トランジション

要素の先頭や末尾で映像を切り替えます。フィルターエフェクトとは別に、要素の境界に設定します。追加・編集の操作は[タイムライン](../../tool-tabs/timeline.md)を参照してください。

## ライブラリでの場所

「ライブラリ」 → トランジション

| トランジション | 表示 | 追加のプロパティ |
| --- | --- | --- |
| クロスディゾルブ | 不透明な要素の不透明度を保ちながら、2 つの映像を徐々に切り替えます。 | なし |
| フェード | 前の映像を透明にしてから、次の映像を表示します。中間点では下のレイヤーが見えます。 | なし |
| ワイプ | 動く境界（直線、広がるボックスやダイヤモンド、回転する時計の針）の後ろに次の映像を表示します。 | 形状、直線の方向、時計回り（クロック） |
| カラーへのディップ | 指定した単色を経由して切り替えます。 | 色。既定値は黒 (`Colors.Black`) |
| ホワイトへのディップ | 白を経由して切り替えます。 | なし |
| プッシュ | 次の映像が入ると同時に、前の映像を画面外へ押し出します。 | 方向 |
| スライド | 静止した前の映像の上に、次の映像が滑り込みます。 | 方向 |
| クロスズーム | 前の映像をズームし、次の映像を元の大きさへズームしながら、両者を徐々に切り替えます。 | 方向、タイルモード |
| アイリス | 画面中央から広がる円の内側、または中央へ閉じていく円の外側に、次の映像を表示します。 | 方向 |
| スプリット | 画面中央から広がる帯の内側に、次の映像を表示します。 | 向き |
| ブラインド | 同時に広がる平行な帯の内側に、次の映像を表示します。 | 角度、分割数 |
| チェッカーボード | 格子状のマス目の内側に次の映像を表示します。1 つおきのマス目から先に開きます。 | 列数、行数 |
| ズームブラー | 放射状のぼかしを伴うズームで 2 つの映像を切り替えます。 | 強さ (%)、方向、タイルモード |
| ウィップパン | 素早いカメラのパンのように、方向ブラーを伴って映像を画面の端へ流します。 | 強さ (%)、方向 |
| グリッチ | ずれた走査線の帯と色ずれで映像を切り替えます。 | 強さ (%) |
| ライトリーク | 画面を横切る暖色の光の帯の下で映像を切り替えます。 | 強さ (%) |

## プロパティ

### 長さ (Duration)

境界の片側が受け持つ時間です。同じレイヤーで隣接する要素の切り替えでは、前の要素の終了のトランジションは境界より前、次の要素の開始のトランジションは境界より後に配置されます。トランジション中に各要素の時間範囲を超える部分では、その端のフレームを保持します。

- **型:** `MediaTime`
- **既定値:** `00:00:00.5`（0.5 秒）
- **アニメーション:** 不可
- **範囲:** `[00:00:00, 01:00:00]`

要素間の共有境界に追加すると、エディターは初期の長さを両側に等分します（各0.25秒）。隣接要素のない端では0.5秒を使います。[トランジション](../../tool-tabs/transition.md)も参照してください。

### イージング (Easing)

トランジションの進み方を指定します。始点や終点を超えるイージング曲線は、その端で止まります。

- **型:** `Easing`
- **既定値:** `LinearEasing`
- **アニメーション:** 不可

### 方向 (Direction)

プッシュ・スライド・ウィップパンと、ワイプ（**直線の方向** という名前で、**直線** の形状に適用されます）で使用します。**左から右**・**右から左**・**上から下**・**下から上** から選択します。

- **型:** `ClipTransitionDirection`
- **既定値:** `LeftToRight`（左から右）
- **アニメーション:** 不可

アイリスの **方向** は **イン（開く）** または **アウト（閉じる）** を選びます。

- **型:** `IrisTransitionDirection`
- **既定値:** `In`（イン）
- **アニメーション:** 不可

クロスズームとズームブラーの **方向** は **拡大** または **縮小** を選びます。

- **型:** `ZoomTransitionDirection`
- **既定値:** `In`（拡大）
- **アニメーション:** 不可

### 形状 (Shape)

ワイプで使用します。**直線** は直線の境界を **直線の方向** に動かします。**ボックス** と **ダイヤモンド** は画面中央から広がります。**クロック** は上から画面中央の周りを回ります。

- **型:** `WipeTransitionShape`
- **既定値:** `Linear`（直線）
- **アニメーション:** 不可

### 時計回り（クロック） (Clockwise)

ワイプで使用します。**クロック** の形状の回転方向を指定します。

- **型:** `bool`
- **既定値:** `true`
- **アニメーション:** 不可

### タイルモード (TileMode)

クロスズームとズームブラーで使用します。縮小する映像が空けた画面の端を埋めます。`Pad` は端を引き伸ばし、`Reflect` は映像を反転し、`Repeat` は映像を繰り返し、`Decal` は透明のままにします。

- **型:** `GradientSpreadMethod`
- **既定値:** `Decal`
- **アニメーション:** 不可

### 角度 (Angle)

ブラインドで使用します。各帯が開く方向を度で指定します。`0` は左から右へ開きます。斜めの角度や負の角度も指定できます。

- **型:** `float`
- **既定値:** `0`
- **アニメーション:** 不可

### 分割数 (Count)

ブラインドで使用します。

- **型:** `int`
- **既定値:** `8`
- **アニメーション:** 不可
- **範囲:** `[1, 64]`

### 列数 / 行数 (Columns / Rows)

チェッカーボードで使用します。

- **型:** `int`
- **既定値:** 列数 `8`、行数 `6`
- **アニメーション:** 不可
- **範囲:** `[1, 64]`

### 強さ (%) (Strength)

ズームブラー、ウィップパン、グリッチ、ライトリークで使用します。`0` では通常のクロスディゾルブになります。

- **型:** `float`
- **既定値:** ズームブラーとグリッチは `65`、ウィップパンは `75`、ライトリークは `70`
- **アニメーション:** 不可
- **範囲:** `[0, 100]`

### 色 (Color)

カラーへのディップで使用します。

- **型:** `Color`
- **既定値:** `Colors.Black`
- **アニメーション:** 不可

### 向き (Orientation)

スプリットで使用します。**水平** は縦の帯を左右に広げ、**垂直** は横の帯を上下に広げます。

- **型:** `ClipTransitionOrientation`
- **既定値:** `Horizontal`（水平）
- **アニメーション:** 不可

## 使い方

境界の両側にトランジションがある場合、見た目は次の要素の開始のトランジションで決まり、前の要素は終了のトランジションの長さを加えます。隣接する要素がない場合は透明な状態との間で切り替わり、下のレイヤーが見えます。
