# オーディオエフェクト

`サウンド` の出力信号を加工するオーディオエフェクトです。

- [**ディレイ**](./delay.md) — 音声にエコー／ディレイをかけます。
- [**イコライザー**](./equalizer.md) — イコライザーを音声に適用します。
- [**コンプレッサー**](./compressor.md) — スレッショルドを超えた信号を圧縮するダイナミックレンジコンプレッサーです。
- [**リミッター**](./limiter.md) — ルックアヘッド付きのブリックウォール型ピークリミッターです。
- [**ゲート**](./gate.md) — スレッショルドを下回っている間、信号を減衰させるノイズゲートです。
- [**タイムストレッチ**](./time-stretch.md) — 音の高さを保ったまま再生速度を変更します。
- [**ノイズ除去**](./noise-reduction.md) — 音声からノイズレベルを学習し、持続する背景ノイズを低減します。
- [**ピッチシフト**](./pitch-shift.md) — 速さを変えずに、音声信号の高さを上げ下げします。
- [**ビブラート**](./vibrato.md) — 音声信号の高さを一定の速さで揺らします。
- [**リングモジュレーター**](./ring-modulator.md) — 音声信号に正弦波を掛け合わせ、金属的な音やロボットのような声にします。
