# オーディオエフェクト

`サウンド` の出力信号を加工するオーディオエフェクトです。

- [**ディレイ**](./delay.md) — 音声にエコー／ディレイをかけます。
- [**イコライザー**](./equalizer.md) — イコライザーを音声に適用します。
- [**コンプレッサー**](./compressor.md) — スレッショルドを超えた信号を圧縮するダイナミックレンジコンプレッサーです。
- [**リミッター**](./limiter.md) — ルックアヘッド付きのブリックウォール型ピークリミッターです。
- [**ゲート**](./gate.md) — スレッショルドを下回っている間、信号を減衰させるノイズゲートです。
