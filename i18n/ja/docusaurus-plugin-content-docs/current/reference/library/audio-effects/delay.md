# ディレイ

音声信号にディレイ／エコーをかけます。`ディレイ時間` だけ遅らせた信号を入力にミックスし直し、`フィードバック` で次の反復に戻すレベルを調整します。

## ライブラリでの場所

「ライブラリ」 → オーディオエフェクト → ディレイ

## プロパティ

### ディレイ時間 (ms) (DelayTime)

ディレイ時間（ミリ秒）。

- **型:** `float`
- **既定値:** `200`
- **アニメーション:** 可
- **範囲:** `[0, 5000]`

### フィードバック (%) (Feedback)

ディレイ音をフィードバックする割合（0 で 1 回のみ、0.7 程度で多重反響）。

- **型:** `float`
- **既定値:** `50`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### ドライミックス (%) (DryMix)

原音（ドライ）のレベル。

- **型:** `float`
- **既定値:** `60`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

### ウェットミックス (%) (WetMix)

ディレイ音（ウェット）のレベル。

- **型:** `float`
- **既定値:** `40`
- **アニメーション:** 可
- **範囲:** `[0, 100]`

## 使い方

短い `ディレイ時間`（100 ms 以下）でスラップバック、長めにすればピンポンディレイやダブ調になります。`ドライミックス`（原音）と `ウェットミックス`（ディレイ音）のバランスで質感を整えます。
