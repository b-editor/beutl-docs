# ソース

外部メディア（動画・画像・バックドロップ）をタイムラインに取り込むための描画オブジェクトです。

- [**動画**](./video.md) — 動画ファイルを描画オブジェクトとして読み込みます。
- [**画像**](./image.md) — 静止画ファイルを描画オブジェクトとして読み込みます。
- [**バックドロップ**](./backdrop.md) — 背景の描画結果を取り込み、合成用の描画オブジェクトとして扱えるようにします。
