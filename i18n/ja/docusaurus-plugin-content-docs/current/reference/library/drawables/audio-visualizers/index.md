# オーディオビジュアライザー

音声信号を可視化する描画オブジェクト（波形・スペクトラム・スペクトログラム）です。

- [**音声波形**](./audio-waveform.md) — 音声信号を波形として可視化します。
- [**スペクトラム**](./audio-spectrum.md) — 音声の周波数スペクトラムを可視化します。
- [**スペクトログラム**](./audio-spectrogram.md) — 時間方向の音声スペクトログラムを可視化します。
