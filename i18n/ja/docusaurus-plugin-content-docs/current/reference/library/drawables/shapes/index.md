# シェイプ

Beutl 標準のシェイプ系の描画オブジェクトです。各シェイプは個別のサイズプロパティを持ち、線や塗りでスタイルを設定できます。

- [**楕円**](./ellipse.md) — 幅と高さから楕円や円を描画します。
- [**矩形**](./rectangle.md) — 幅と高さから矩形を描画します。
- [**角丸四角形**](./rounded-rectangle.md) — 角を丸めた矩形を描画します。
- [**ジオメトリー**](./geometry.md) — 任意のパスを描画します。
- [**テキスト**](./text.md) — 指定したフォントとスタイルで文字列を描画します。
