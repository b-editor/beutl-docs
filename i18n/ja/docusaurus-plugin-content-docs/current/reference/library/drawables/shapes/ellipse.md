# 楕円

幅と高さで定義される領域を楕円（幅と高さが等しい場合は真円）として描画します。

## ライブラリでの場所

「ライブラリ」 → 楕円

## プロパティ

### 幅 (Width)

楕円の幅（ピクセル）。バウンディングボックスの横幅です。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, ∞)`

### 高さ (Height)

楕円の高さ（ピクセル）。バウンディングボックスの縦幅です。

- **型:** `float`
- **既定値:** `100`
- **アニメーション:** 可
- **範囲:** `[0, ∞)`

## 共通プロパティ

このオブジェクトは `シェイプ` を継承しているため、基底クラスで宣言された[共通プロパティ](../../common-properties.md)も利用できます。

## 使い方

タイムラインに配置し、`横幅` と `高さ` を設定します（アニメーションさせると拡大・縮小ができます）。塗りつぶしに使うブラシを設定し、必要に応じてストロークを使用して、輪郭を描画できます。
