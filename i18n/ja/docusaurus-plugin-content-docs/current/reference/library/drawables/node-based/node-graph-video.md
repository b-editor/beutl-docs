# ノードグラフ（動画）

ノードグラフによってピクセル出力を生成する描画オブジェクトです。専用のノードグラフエディタで編集し、入力が変化するたびに再計算されます。

## ライブラリでの場所

「ライブラリ」 → ノードグラフ（動画）

## プロパティ

### モデル (Model)

計算するノードグラフモデル。

- **型:** `GraphModel?`
- **既定値:** なし (`null`)
- **アニメーション:** 不可

## 共通プロパティ

このオブジェクトは `描画オブジェクト` を継承しているため、基底クラスで宣言された[共通プロパティ](../../common-properties.md)も利用できます。

## 使い方

プロパティからグラフエディタを開き、ノードを接続して描画パイプラインを構築すると、その結果がこの描画オブジェクトの出力になります。再利用可能なパイプラインの構築に便利です。
