# 描画オブジェクト

Beutl 標準の描画オブジェクト群（キャンバスに何かを描画するもの）をまとめています。

- [シェイプ](./shapes/index.md) — 基本図形やテキスト
- [ソース](./sources/index.md) — 動画 / 画像 / バックドロップソース
- [パーティクル](./particles/index.md) — パーティクルエミッター
- [オーディオビジュアライザー](./audio-visualizers/index.md) — 波形 / スペクトラム / スペクトログラム
- [ノードベース](./node-based/index.md) — ノードグラフで駆動する描画オブジェクト
- [コンテナ](../containers/index.md) — 複数のオブジェクトをグループ化するためのコンテナ
