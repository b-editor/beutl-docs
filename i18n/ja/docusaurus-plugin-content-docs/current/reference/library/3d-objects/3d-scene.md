# 3Dシーン

:::caution 試験的な機能

この 3D 機能は開発中であり、API は予告なく変更される可能性があります。

:::

カメラ・ライト・3D オブジェクトを格納し、その結果を 2D の描画オブジェクトとしてレンダリングする 3D シーンコンテナです。3D 機能は試験的に提供されています。

## ライブラリでの場所

「ライブラリ」 → 3D（実験的） → 3Dシーン

## プロパティ

### カメラ (Camera)

シーンの描画に使うカメラ。

- **型:** `Camera3D?`
- **既定値:** `PerspectiveCamera`
- **アニメーション:** 不可

### 環境色 (AmbientColor)

グローバルなアンビエントライトの色。

- **型:** `Color`
- **既定値:** `#FFFFFFFF` (白)
- **アニメーション:** 可

### 環境光強度 (AmbientIntensity)

アンビエントライトの強さ。

- **型:** `float`
- **既定値:** `0.2`
- **アニメーション:** 可
- **範囲:** `[0, 1]`

### レンダリング幅 (RenderWidth)

シーンをラスタライズする幅（ピクセル）。

- **型:** `float`
- **既定値:** `1920`
- **アニメーション:** 可
- **範囲:** `[1, 8192]`

### レンダリング高さ (RenderHeight)

シーンをラスタライズする高さ（ピクセル）。

- **型:** `float`
- **既定値:** `1080`
- **アニメーション:** 可
- **範囲:** `[1, 8192]`

プロパティパネルでは、**レンダリング幅** と **レンダリング高さ** が 1 つの **レンダリングサイズ** の行にまとめて表示されます。[1 行にまとめて表示される値](../../../get-started/keyframe.md#joined-rows)を参照してください。

### 背景色 (BackgroundColor)

レンダリングされたシーンの背景色。

- **型:** `Color`
- **既定値:** `Colors.Transparent`
- **アニメーション:** 可

## 共通プロパティ

このオブジェクトは 描画オブジェクト を継承しているため、基底クラスで宣言された[共通プロパティ](../common-properties.md)も利用できます。

## 使い方

ライブラリから **3Dシーン** を単独で追加すると（タイムラインやプレビューへのドロップ、または **要素を追加**）、すぐに何かが表示されるように、そのすぐ下のレイヤーに **立方体** も追加されます。3Dシーンの要素は[ポータル](../portal/portal-object.md)を通して下の 5 つのレイヤーの 3D オブジェクトとライトを取り込むので、続くレイヤーにさらに追加できます。2 つの要素は 1 回の取り消し単位で、隣り合うレイヤーに追加されます。そこのレイヤーが使われているかロックされているときは、2 つ一緒に空いているレイヤーへ置かれます。それらのレイヤーにシーンと時間が重なる 3D オブジェクトがないときは、要素に[警告](../../tool-tabs/timeline.md#element-warnings)が表示されます。
