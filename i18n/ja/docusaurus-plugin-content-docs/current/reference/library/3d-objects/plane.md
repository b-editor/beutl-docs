# 平面

:::caution 試験的な機能

この 3D 機能は開発中であり、API は予告なく変更される可能性があります。

:::

幅・高さおよび分割数で定義される 3D の平面プリミティブです。地面・ビルボード・変形させたいサーフェスなどに使います。

## ライブラリでの場所

「ライブラリ」 → 3D（実験的） → 平面

## プロパティ

### 幅 (Width)

ローカル X 軸方向の幅。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.001, ∞)`

### 高さ (Height)

ローカル Z 軸方向の高さ（平面は XZ 平面上にあり、法線は Y 軸正方向）。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.001, ∞)`

### 幅の分割数 (WidthSegments)

幅方向の分割数。

- **型:** `int`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[1, ∞)`

### 高さの分割数 (HeightSegments)

高さ方向の分割数。

- **型:** `int`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[1, ∞)`

## 共通プロパティ

このオブジェクトは `3Dオブジェクト` を継承しているため、基底クラスで宣言された[共通プロパティ](../common-properties.md)も利用できます。
