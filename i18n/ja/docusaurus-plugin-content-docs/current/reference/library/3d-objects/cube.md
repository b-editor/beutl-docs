# 立方体

:::caution 試験的な機能

この 3D 機能は開発中であり、API は予告なく変更される可能性があります。

:::

幅・高さ・奥行きで定義される 3D の立方体プリミティブです。位置・回転・スケール・マテリアルは 3Dオブジェクト から継承します。

## ライブラリでの場所

「ライブラリ」 → 3D（実験的） → 立方体

## プロパティ

### 幅 (Width)

ローカル X 軸方向の幅。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.001, ∞)`

### 高さ (Height)

ローカル Y 軸方向の高さ。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.001, ∞)`

### 深度 (Depth)

ローカル Z 軸方向の奥行き。

- **型:** `float`
- **既定値:** `1`
- **アニメーション:** 可
- **範囲:** `[0.001, ∞)`

## 共通プロパティ

このオブジェクトは 3Dオブジェクト を継承しているため、基底クラスで宣言された[共通プロパティ](../common-properties.md)も利用できます。
