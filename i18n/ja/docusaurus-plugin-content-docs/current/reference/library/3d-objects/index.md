# 3D（試験的）

試験的な 3D オブジェクト群です：シーンコンテナ、プリミティブ、モデル、ライトなど。3D 機能は現在開発中です。

- [**3Dシーン**](./3d-scene.md) — カメラとライティングを持つ 3D レンダリングコンテナです。
- [**立方体**](./cube.md) — 幅・高さ・奥行きで定義される 3D の立方体プリミティブです。
- [**球体**](./sphere.md) — 半径と分割数を指定する 3D の球体プリミティブです。
- [**平面**](./plane.md) — 幅と高さおよび分割数で定義される 3D の平面プリミティブです。
- [**モデル**](./model.md) — 外部の 3D モデルファイルを読み込んで描画します。
- [**平行光源**](./directional-light.md) — 一方向からシーンを照らす平行光源です。
- [**点光源**](./point-light.md) — 一点から全方向に光を放つ点光源です。
- [**スポットライト**](./spot-light.md) — 内側角・外側角を持つ円錐状のスポットライトです。
